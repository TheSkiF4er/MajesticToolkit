# MajesticToolkit 1.8.0 — Расширенная модерация
> **Архив релиза.** Здесь сохранены возможности, проверки и ограничения, актуальные на момент выпуска 1.8.0. Полная последовательность изменений — в [истории версий](../CHANGELOG.md).


## Релиз

Новый рабочий раздел **«Центр модерации»** объединяет действующие сервисы 1.7.x:

- **Обзор**: фактические показатели активных и просроченных жалоб, входящих событий, решений, подписок и локального аудита. Списки ближайших дел и новых событий с прямыми переходами. Период статистики 7/14/30/90 дней.
- **Жалобы и очередь**: полный Complaint Manager 2.0 с фильтрами, доказательствами, workflow и сохраняемой пакетной очередью; все существующие операции работают внутри центра.
- **Мониторинг и входящие**: подписки XenForo, ручная/периодическая проверка, события новых тем и ответов, приём в Complaint Manager.
- **Реестр и экспорт**: регистрация проверенного решения, история статусов, CSV/JSON/TXT/BBCode с действующим скачиванием.
- **Аналитика, SLA и журнал**: существующие действующие настройки сроков, локальная автоматизация, аудит и показатели.

Поддерживаются поиск и маршруты между разделами, отдельные профильные настройки вкладки и периода, клавиатурная навигация, popup и адаптивная раскладка. Новые данные не подмешиваются между проектами, серверами и профилями.

## Backup v16

Общий архив v16 содержит все данные прежнего Backup v15 (шаблоны, жалобы, доказательства, правила, редакции, калькулятор, черновики, мониторинг, реестр, аудит) и новые настройки Moderation Center в профилях. При импорте v1–v15 сохраняется прежняя логика проверки, совместимости и восстановления, новая конфигурация имеет безопасные значения по умолчанию. Ограничение архива 48 МиБ.

## Границы безопасности

Toolkit не публикует решения, не закрывает темы автоматически и не выдаёт игровые наказания. Фоновые проверки требуют действующих разрешений и доступной сессии форума. Отметки публикации/исполнения реестра являются локальными до официального подтверждения.

## Проверка

Запустить `npm run verify` и `npm run test:browser`. Браузерные сценарии используют локальные XenForo DOM-фикстуры. Проверка работающего авторизованного форума, Firefox Android и Safari на реальных устройствах не подтверждается этими тестами.
