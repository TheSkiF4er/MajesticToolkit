# MajesticToolkit 2.0.8 — Судебные доказательства и досье
> **Архив релиза.** Здесь сохранены возможности, проверки и ограничения, актуальные на момент выпуска 2.0.8. Полная последовательность изменений — в [истории версий](../CHANGELOG.md).


## Работа с судебными доказательствами

Откройте «Government & Justice» → «Судебные дела» → карточку дела. В блоке «Судебные доказательства» доступны создание HTTPS-ссылки, загрузка локального файла (до 32 МиБ, поддерживаемые форматы Evidence Vault), прикрепление ранее сохранённого материала, редактирование названия/описания/категории, привязка к конкретному заседанию или ходатайству. Файл физически хранится в Evidence Vault (IndexedDB), а судебное дело содержит проверенный ID и снимок метаданных. Действия записываются в журнале дела. Закрытые и архивные дела доступны только для чтения.

Проверка доказательства сопоставляет неизменяемые параметры снимка с Evidence Vault, для бинарного файла повторно вычисляет SHA-256. При несовпадении операция блокируется. Удаление материала из Evidence Vault запрещено, пока он прикреплён к судебному делу. Исключение из дела требует причины и оставляет событие в журнале; исходный файл при этом сохраняется в Vault. Доступ к материалам ограничивается профилем RP-сервера.

## Экспорт судебного досье

Кнопка «Сформировать судебное досье» создаёт снимок дела, суда, ведомства и всех связанных документов (включая редакции Document Studio, нормативные ссылки в ведомственных решениях). Включены участники, заседания, протоколы, ходатайства, сроки, доказательства и журнал дела. Доступны ZIP, JSON, HTML и TXT. ZIP использует формат STORE и включает манифест с SHA-256 содержимого и вложений; доступные файлы повторно проверяются, отсутствующие фиксируются отдельно. В окне доступна проверка ранее сформированного ZIP.

Досье и архив не отправляются на сервер автоматически. SHA-256 и журнал позволяют обнаруживать изменения, но не являются квалифицированной электронной подписью, не доказывают авторство и не подтверждают юридическую силу документов. Импорт данного ZIP в судебное дело не предусмотрен: восстанавливайте дела через общий Backup v18, файлы — через переносимый Evidence Vault.

## Совместимость и проверки

Хранилища Government Store и Document Studio не меняют префиксы или формат Backup v18. Судебные дела версий 2.0.5–2.0.7 без `evidence` читаются с пустым реестром, а при следующем изменении получают поле `evidence: []`. Действующие ID и история документов сохраняются. В комплекте — модульные проверки, сквозной браузерный тест и обычные команды `npm test`, `npm run build`, `npm run verify`.
