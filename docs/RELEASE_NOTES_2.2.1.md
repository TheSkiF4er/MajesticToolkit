# MajesticToolkit 2.2.1 — Tactical Workspace

Дата: 2026-11-19. Базовая версия: 2.2.0.

## Рабочий пользовательский интерфейс

В навигации и popup добавлен самостоятельный раздел `Tactical Toolkit` (`#tactical`). Он использует **существующие** реестры Crime & Territory Operations, Families & Membership и Organizations & Assets, а не создаёт второй журнал каптов или территорий.

- Dashboard по активному RP-профилю: активные территории, запланированные и просроченные RP-события, завершённые события, семьи и организации. Просрочка рассчитывается из сохранённой даты события и локальной текущей даты, без скрытого серверного расписания.
- Пять вкладок: Обзор, Территории, Капты и события, Семьи и организации, Недавние.
- Живой поиск по названиям, районам, владельцам, участникам и примечаниям. Фильтры событий: все, запланировано, просрочено, завершено, отменено. Избранное и история открытий сохраняются по RP-профилям.
- Кнопки открытия реально переводят в Economy & Crime и открывают нужную территорию, протокол RP-события, карточку семьи или организации. «+ Территория» и «+ Капт / RP-событие» открывают штатные формы создания. Все изменения видны после возвращения в Tactical Workspace.
- Настройки тактической панели хранятся отдельно в `mtTacticalWorkspaceV221` и очищаются при удалении RP-профиля. Никаких миграций исходных записей Crime, Families и Organizations не требуется. Tactical Toolkit можно выбрать стартовым разделом в настройках.
- Существующие маршруты `#economy`, данные и Backup v20 остаются совместимыми. В Backup v20 по-прежнему сохраняются собственно территории, события, семьи и организации; персональные настройки Tactical Workspace являются локальной настройкой интерфейса.

## Проверка

```bash
npm run verify
npm run test:browser:tactical
npm run test:browser:crime
npm run test:browser:economy
```

Unit-тесты проверяют фильтры, подсчёт реальных событий, смену владельца в завершённом капте, поиск, изоляцию RP-профилей, избранное и устаревшие ссылки. Chromium E2E проходит создание организаций, территории и капта через штатные формы, переход в редактор из Tactical, сохранение поиска и фильтров, возврат в историю и переключение профиля. CI запускает этот сценарий наряду с существующими.

## Ограничения релиза

Версия 2.2.1 не включает интерактивную карту, аирдропы, маршруты и симуляции. Они запланированы на 2.2.2–2.2.8. Система не получает позиции игроков или события напрямую с Majestic RP; локальные тесты и браузерные фикстуры не заменяют проверку на действующем RP-сервере. Установленные расширения на всех четырех целевых платформах должны тестироваться отдельно.
