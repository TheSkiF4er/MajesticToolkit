# MajesticToolkit 2.1.5 — Организации и имущество
> **Архив релиза.** Здесь сохранены возможности, проверки и ограничения, актуальные на момент выпуска 2.1.5. Полная последовательность изменений — в [истории версий](../CHANGELOG.md).


## Что работает

- **Организации:** восьмая вкладка `#economy` → «Организации», создание, редактирование, выбор вида, поиск по организациям, составу, подразделениям, должностям и инвентарным номерам, архивирование и восстановление.
- **Структура:** создание и изменение подразделений с иерархией, запрет циклов, защита от архивации используемых подразделений. Должности привязаны к подразделениям, имеют приоритеты и собственный жизненный цикл.
- **Сотрудники:** вступление, назначение и перевод на другую должность, выход из организации. Запрещены одновременные дубликаты никнейма внутри организации и выход лица с закреплённым активным имуществом.
- **Имущество:** реестр транспортных средств, недвижимости, оборудования и прочих активов; инвентарные номера, оценки в целых игровых долларах, ответственные, изменение реквизитов, списание и восстановление. CSV-экспорт с защитой от формульных инъекций.
- **Склад:** реальные остатки Trading & Inventory выводятся в карточке организации по точному текущему названию владельца. Имущество реестра и складские товары отображаются раздельно: складская стоимость не суммируется с оценкой реестровых активов, чтобы не удваивать стоимость.
- **История:** операции сохраняются как проверяемая последовательность событий с датой, причиной и исходными идентификаторами; архив запрещён при активном составе, реестровых активах или товарных остатках. Переименование запрещено, если название организации уже используется складской историей.
- **Профили:** данные изолированы по RP-профилям и удаляются вместе с профилем с восстановлением в случае сбоя.
- **Backup v19:** добавлено необязательное поле `organizations`, которое проверяется при экспорте и импорте; старые резервные копии без поля не удаляют организации, если их профили остаются доступны. При ошибке восстановления используется прежняя точка отката.

## Ограничения

Система ведёт **локальный RP-реестр**, а не подтверждённые игровые роли или серверное владение. Склад 2.1.3 связывается с организациями по текстовому имени владельца: ранее введённые и иначе написанные названия не объединяются автоматически. Финансовые счета и платежи организаций появятся в релизе 2.1.7. Отдельные учётные записи участников, сетевые синхронизации и серверные разрешения не реализованы.

## Проверки

Для обновления распакуйте патч поверх полного 2.1.4 и выполните `npm run verify`, `npm run test:browser:organizations`, `npm run test:browser:families`, `npm run test:browser:inventory`, `npm run test:browser:marketplace` и `npm run test:browser:economy`. Браузерные проверки используют локальные фикстуры, а не реальный аккаунт RP.
