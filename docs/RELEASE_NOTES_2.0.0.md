# MajesticToolkit 2.0.0 — ИИ-помощник и поддержка
> **Архив релиза.** Здесь сохранены возможности, проверки и ограничения, актуальные на момент выпуска 2.0.0. Полная последовательность изменений — в [истории версий](../CHANGELOG.md).


## Что готово

- Единый AI Workspace: **Чат / Правила / Жалобы / Поддержка / Контексты и черновики**. Это действующие интерфейсы и хранилища версий 1.9.1–1.9.5, а не новые дублированные записи.
- Локальный AI Gateway для настоящего OpenAI Responses API: потоковые ответы, отмена, HTTP-ошибки, лимиты, `store:false`, запрет доступа обычных веб-сайтов, токен в памяти интерфейса и ключ OpenAI исключительно в окружении Node.js.
- Правила: выбор проверенных редакций, точные цитаты и URL локальных источников. Жалобы: выбранные доказательства, события и правила, структурированный отчёт и ручное сохранение черновика. Поддержка: локальная диагностика без AI и необязательный облачный ответ.
- **Безопасность прерывания чата**: неполный поток или отмена не записываются в историю и не участвуют в следующем запросе; при переключении профиля запрос прерывается и ключ шлюза удаляется из памяти.
- **Backup v18**: подтверждаемый чекбокс для экспорта сохранённых AI-диалогов, контекстов и черновиков всех профилей. По умолчанию эти данные исключены. В резервную копию не входят ключи OpenAI, токены шлюза и согласия. При импорте AI отключается до повторного явного включения пользователем.
- Переносимый ZIP v18 проверяет манифест, CRC-32 и SHA-256; по-прежнему включает бинарные файлы Evidence Vault, если они доступны и проверены. Backup v1–v17 совместимы, истории AI в старых копиях нет.
- AI-сохранения добавлены в локальные точки восстановления после импорта (при соблюдении общего лимита 20 МиБ).

## Установка и запуск

1. Распакуйте патч 2.0.0 поверх **полного** проекта 1.9.5 с сохранением путей.
2. Node.js 22: `npm run verify`, `npm run test:browser`.
3. Настройте `OPENAI_API_KEY` и независимый `MT_AI_GATEWAY_TOKEN`, затем `npm run ai:gateway`. **Не вводите OpenAI API-ключ в браузер.**
4. В Workspace → AI / Поддержка явно включите AI, разрешите `http://127.0.0.1/*`, введите отдельный токен шлюза и проверьте подключение. Любой AI-запрос требует предпросмотра и подтверждения.
5. Для переноса истории AI откройте «Резервные копии», выберите чекбокс AI-истории, затем экспортируйте JSON v18 или Portable ZIP v18. Экспортированные данные не зашифрованы — защищайте файл вручную.

## Проверки и честные ограничения

- Проверка автоматически охватывает валидацию резервных копий v17/v18, ZIP, запрет скрытых секретов, HTTP-шлюз, CORS, изоляцию профилей, интерфейс чата и прерванные потоки.
- E2E работают на автономных XenForo-фикстурах, сеть OpenAI моделируется; **оплачиваемые запросы к реальному OpenAI API без пользовательских ключей и авторизованные форумы не проверены**.
- Safari и Firefox Android получают проверенные пакеты, но тестирование на физических устройствах отдельно требуется для окончательного production sign-off.
- AI не проверяет содержимое внешних ссылок и файлы, которые не были явно переданы. Цитаты и AI-рекомендации не являются официальными решениями. Публикация и санкции выполняются вручную.
