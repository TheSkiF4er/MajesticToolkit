# MajesticToolkit 2.1.3 — Trading & Inventory

## Готовый функционал

- Седьмая вкладка Economy & Crime — **«Склад и имущество»** (`#economy`). Содержит остатки, поиск, журнал движений и кнопки реальных операций.
- **Покупка (оприходование)** из активного товара Marketplace: количество, стоимость за штуку, комиссия, дата, владелец, примечание. Закупка создаёт неизменяемую партию.
- **Частичная продажа** конкретной партии с комиссией и расчётом себестоимости проданных единиц. Закупочная комиссия распределяется целочисленно по фактически выбывшим единицам, остаток остаётся на складе.
- **Передача** между личной собственностью, семьёй и организацией без фиктивной выручки. **Резерв и снятие резерва**; зарезервированные единицы нельзя продать, передать или списать. **Списание** отдельным убытком.
- **Имущество**: уникальный инвентарный номер для партии из одной единицы, история владельцев и передача между ними. Владельцы — локальные текстовые RP-обозначения; реестры семей и организаций появятся в 2.1.4–2.1.5.
- **Журнал и отмена**: история операций не переписывается. Отмена последней операции партии записывается отдельным событием и пересчитывает склад; отмена при зависимых операциях запрещена. Поиск и безопасный CSV со всеми операциями и отметкой отмен.
- **Финансовая сводка** склада: закупки, выручка после комиссий, COGS, реализованная прибыль, убытки от списаний, остатки по себестоимости. Эти данные **не являются** дополнительными `cash`/`deal` в старом учёте, поэтому автоматического двойного начисления нет. Автоматическое списание с семейных касс запланировано на 2.1.7.
- **Backup v19** дополнен опциональным `tradingInventory`, проверяемым при экспорте и импорте с учётом `marketplace` и профилей. Старые v19 без этого поля не стирают существующий склад. Откат неудачного восстановления сохраняет исходные данные. Товары с историей складских движений нельзя удалить из каталога, но можно архивировать.

## Установка и проверки

1. Распаковать только изменённые файлы поверх полного исходного проекта 2.1.2.
2. `npm run verify` (модули, сборки Chromium/Firefox/Firefox Android/Safari, контроль пакетов).
3. `npm run test:browser:inventory` и `npm run test:browser:marketplace` (Chromium/Playwright).

Хранение локальное в `browser.storage.local`; при наличии Web Locks записи Marketplace и Inventory сериализуются также между вкладками расширения. В браузерах без Web Locks используется очередь операций текущего процесса. Нет сетевой синхронизации, подтверждённых прав собственности игрового сервера или рыночных котировок извне.
