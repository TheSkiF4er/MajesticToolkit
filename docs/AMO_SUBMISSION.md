# Публикация MajesticToolkit на addons.mozilla.org

1. Выберите **«На этом сайте»** (listed). Сборка `release/MajesticToolkit-1.5.1-firefox.zip` предназначена для Firefox Desktop. Для Android есть отдельная сборка, её нужно проверить на устройстве и отправлять отдельно по требованиям AMO.
2. В манифесте задан стабильный ID `majestictoolkit@theskif4er.github.io`, `gecko.strict_min_version: 140.0`, `gecko_android.strict_min_version: 142.0` и встроенная декларация данных. ID **нельзя менять после публикации**, иначе существующие пользователи не получат обновления. Если прежняя версия AMO уже зарегистрирована под другим ID, сохраните именно зарегистрированный ID и пересоберите пакет.
3. Обязательная передача данных: `none`. Необязательные категории при подключении Google: `authenticationInfo`, `personallyIdentifyingInfo`, `personalCommunications`, `websiteContent`. Firefox запрашивает разрешение при нажатии «Подключить Google». Не заявляйте отсутствие любых передач данных при включённой Google-интеграции.
4. Не добавляйте `update_url`: при публикации **на AMO** обновления идут через инфраструктуру Mozilla, этот параметр используется при самостоятельном распространении.
5. Перед подачей: `npm run verify`. В CI запускать `addons-linter@10.14.0` на обоих ZIP. Локально без npm-доступа можно выполнить только встроенные проверки; успешная AMO-модерация не гарантирована.
6. В карточке AMO используйте достоверное описание, действующие скриншоты, ссылку на этот файл политики приватности, опубликованный по постоянному публичному URL (например, GitHub `docs/PRIVACY.md` после merge), и описание причин запрашиваемых разрешений.
7. Заполните `Source Code` URL: `https://github.com/TheSkiF4er/MajesticToolkit`. Не утверждайте, что Google OAuth протестирован на реальном аккаунте, пока он действительно не проверен.
8. Если ZIP `1.5.1` уже был принят или загружен как версия с тем же номером, поднимите версию во всех манифестах и `package.json` до следующей версии, обновите имена пакетов/проверки и отправляйте обновление.

Для Firefox 1.5.1 используйте пакет и исходники, созданные из одного и того же дерева. Перед повторной загрузкой проверьте, разрешает ли AMO новую версию в текущей заявке.
