# Публикация MajesticToolkit в Mozilla Add-ons

**Актуальная документация для версии 2.4.0** · [Сборка Firefox](AMO_BUILD.md) · [Политика конфиденциальности](PRIVACY.md)

## Перед отправкой

1. Соберите Firefox-пакеты командой `npm run build-for-amo`; затем выполните `npm run verify` и сверку SHA-256. Для компьютера используется `release/MajesticToolkit-2.4.0-firefox.zip`, для Android — отдельный `release/MajesticToolkit-2.4.0-firefox-android.zip`.
2. Проверьте, что заявляемая версия совпадает с `package.json` и манифестом внутри архива. У Mozilla не следует повторно подавать другой пакет с уже использованным номером версии.
3. Убедитесь, что идентификатор Firefox остаётся постоянным: `majestictoolkit@theskif4er.github.io`. Изменение ID нарушит преемственность установленного дополнения и его локальных данных.
4. Учитывайте минимальные версии, указанные в текущем манифесте: `gecko.strict_min_version: 140.0` и `gecko_android.strict_min_version: 142.0`. Фактическую поддержку устройств подтвердите отдельно.
5. Подготовьте исходники той **же редакции**, что и приложенный ZIP. Не включайте в исходный пакет собранные `dist/` и `release/` вместо исходников.

## Декларация данных и разрешений

В манифесте указаны обязательные категории передачи данных `required: ["none"]`. Необязательные категории, которые могут использоваться при подключении Google: `authenticationInfo`, `personallyIdentifyingInfo`, `personalCommunications`, `websiteContent`.

- Доступ к форумам, видеосайтам, Google API, справочникам, серверным API и локальному шлюзу запрашивается по соответствующему действию пользователя.
- В `optional_host_permissions` также присутствует `https://*/*`; при заполнении анкеты магазина объясните реальный сценарий его использования и оцените возможность сузить этот доступ в будущих версиях.
- При импорте страницы Fletcher Wiki разрешение позволяет прочесть **видимый текст открытой пользователем страницы**; скрытого обхода защиты сайта не предусмотрено.
- Не утверждайте, что «передача данных отсутствует всегда»: пользователь может явно включить Google, ИИ или самостоятельно размещённый облачный сервер. Описывайте условия и объём передачи честно.

Публичная политика: [docs/PRIVACY.md](https://github.com/TheSkiF4er/MajesticToolkit/blob/main/docs/PRIVACY.md). Перед публикацией проверьте, что ссылка доступна без авторизации.

## Карточка расширения

- Выберите подходящий режим публикации, заполните русскоязычное описание и актуальный список функций без обещаний непроверенного автоматического доступа к данным RP-серверов.
- Добавьте реальные скриншоты текущей версии и описание причин для разрешений.
- Укажите исходный код: `https://github.com/TheSkiF4er/MajesticToolkit`.
- Для распространения через AMO не добавляйте собственный `update_url`, если обновления должны доставляться Mozilla.
- Подготовьте отдельную приёмку Firefox Android. Наличие архива ещё не означает разрешения магазина на распространение на всех устройствах.

## После подачи

Проверяйте отчёт Mozilla Add-ons Linter, замечания модерации и реальные установки подписанного пакета. Автоматическая упаковка не гарантирует принятие магазина. Если новая версия требует изменения кода, увеличьте номер выпуска во всех манифестах и метаданных перед повторной отправкой.
