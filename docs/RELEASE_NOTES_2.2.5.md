# MajesticToolkit 2.2.5 — Карта территорий и захватов
> **Архив релиза.** Здесь сохранены возможности, проверки и ограничения, актуальные на момент выпуска 2.2.5. Полная последовательность изменений — в [истории версий](../CHANGELOG.md).


## Новые возможности

- В `#tactical` → **Карта** → **Территории и капты на карте** пользователь может связать существующий полигон карты с сохранённой территорией из Crime & Territory Operations. Сначала создайте территорию в `#economy` → «Территории и капты», затем нарисуйте полигон на карте инструментом «Зона», выберите его и нажмите «Привязать полигон».
- Каждая территория может иметь одну картографическую зону, а каждый полигон — не более одной привязки. Ссылки используют устойчивые ID территорий и полигонов, а не их редактируемые названия.
- Связанные полигоны подсвечиваются цветом владельца — семьи, организации или «Без владельца» — и показывают названия территории и владельца. Поиск и выбор зоны доступны в обычном редакторе карты; кнопка «На карте» перемещает просмотр к нужному полигону.
- Поле «Владение на дату» воспроизводит смену владельцев по завершённым каптам, сортируя их в том же порядке, что и Crime Core. Запланированные или отменённые капты не изменяют владение, ничьи и победы защитника сохраняют исходного владельца.
- Для выбранной связанной зоны видны капты, дата, статус, результат и переход к исходному событию или редактору территории. «Обновить капты» подгружает изменённые данные из действующего Crime Store.
- Привязки хранятся атомарно внутри той же записи карты IndexedDB с проверкой версии разметки, SHA-256 подложки и RP-профиля; устаревшая вкладка не перезаписывает более новую связь. Нельзя удалить привязанный полигон при ручном удалении или импорте JSON-разметки. Для удаления сначала выполните «Отвязать».
- Карты 2.2.2–2.2.4 открываются без миграции и получают пустой список привязок; ранее созданные территории и история каптов не изменяются.

## Ограничения

- Это локальное отображение записей RP-событий, а не отслеживание положения игроков и не синхронизация с сервером Majestic RP.
- Карта, изображения, разметка и привязки **не входят в Backup v20**. Экспорт разметки JSON (2.2.3) переносит только геометрию и слои, но не связи с территориями: перенос полной карты с привязками запланирован для Backup v21 (2.2.9).
- При восстановлении отдельного старого реестра территорий в другой набор ID привязка в карте может стать осиротевшей. Она отображается как «Отсутствующая территория» и может быть отвязана вручную. Защита сквозных связей при полном восстановлении — задача 2.2.9.

## Проверки

- `npm test` — Node.js: исходные тесты + новые сценарии привязки, истории владельцев, профилей, несвязанных зон и проверки полигонов.
- `npm run test:browser:territory-map` — Chromium: реальная подложка, Canvas, привязка, изменение владельца по дате, сохранение в IndexedDB-адаптере и запрет удаления связанной зоны.
- `npm run verify` — сборка и проверка четырёх архивов расширения Chromium, Firefox, Firefox Android, Safari.

Нативный IndexedDB установленного расширения, все целевые браузеры и реальные игровые серверы требуют отдельной ручной проверки.
