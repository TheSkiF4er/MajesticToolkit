# MajesticToolkit 1.5.8 — Navigation 2.0

В рабочем пространстве откройте «Форум» → «Пользовательская навигация XenForo». Создайте ссылку или закладку, укажите профиль, форум, группу (например `Работа/Жалобы`), размещение, иконку, порядок и способ открытия. Закрепление, перетаскивание за ↕ и кнопки ↑/↓ меняют порядок, не затрагивая штатную навигацию XenForo.

На форуме нажмите MT → «Навигация» или Alt+Shift+N. Панель содержит контекст страницы, сохранение закладки, быстрые команды, локальный поиск по существующим данным, меню и выбор профиля этого форума. Записи сохраняются в локальном хранилище. Закладки доступны только в соответствующем профиле и на его форуме. Ссылки ограничены HTTPS. История выключена по умолчанию; при включении хранит до 50 последних поддерживаемых страниц без query-параметров; очистка в панели или рабочем пространстве. Дата открытия закладки фиксируется при её открытии через Toolkit.

Существующие ссылки и шаблоны не меняются при обновлении. Метаданные навигации входят в Backup v14; история посещений не экспортируется. Binder-пакеты остаются форматом шаблонов и простых ссылок. Кастомизация самого форума запланирована на 1.5.9.

Проверка: `npm run verify`; браузерные фикстуры: `npm run test:browser`.
