# Приватность MajesticToolkit

MajesticToolkit не использует собственный backend, обязательную регистрацию или встроенную аналитику использования. Шаблоны, жалобы, личные финансы, законодательство, ведомства и документы сохраняются в локальном хранилище браузера.

Когда пользователь явно подключает Google, расширение обращается напрямую к Google API с запрошенными OAuth-полномочиями для работы с документами и резервными копиями. Сервис Google обрабатывает предоставленные ему данные согласно собственным условиям; MajesticToolkit не хранит OAuth-токены в экспортируемых копиях.

При открытии Fletcher Wiki/Docossum эти сайты могут самостоятельно получать стандартные сетевые данные браузера. Скрытого обхода страниц и фонового сбора их содержимого расширение не осуществляет. Форумы и видеосервисы обрабатываются только после предоставления соответствующих разрешений. Данные можно удалить через интерфейс расширения, сброс хранилища или удаление расширения (предварительно сохраните экспорт).
