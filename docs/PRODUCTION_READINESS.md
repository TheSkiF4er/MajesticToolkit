# MajesticToolkit 1.5.0 — Production Readiness

## Что проверено кодом

- **Браузерные тесты:** `tests/browser-e2e.py` действительно запускает Chromium или Firefox через Playwright и исполняет контентный скрипт в реальном DOM. Используются автономные фикстуры, отражающие типовые элементы XenForo: текстовый редактор, contenteditable/Froala, ссылки навигации, меню модерации и публичная карточка. Проверяется сохранение пользовательских данных через mocked runtime bridge и блокирование небезопасного HTML. Тесты не обращаются к действующим форумам.
- **Контроль источника:** `message-security.mjs` проверяет идентификатор расширения, полный HTTPS-домен, контекст верхнего фрейма и отделяет возможности открытых форумных страниц от внутренних UI-страниц.
- **Профили:** добавление и сканирование жалоб привязаны к профилю, чей `forumUrl` соответствует адресу действующего форума, а не к произвольному выбранному профилю.
- **Видео:** запрещено добавлять доказательства в жалобу другого активного игрового профиля.
- **Обновления:** регистрация существующего контентного скрипта сверяется по фактическим скриптам и условиям запуска; изменившиеся версии переустанавливаются.
- **Производительность:** неизменённые наблюдения тем не инициируют новые записи в хранилище чаще нужного; API мониторинга ограничен 1 МиБ во время чтения потока, а не после загрузки всего тела.
- **Тесты:** покрывают злонамеренные URL, фреймы, длинные и циклические сообщения, восстановление записи, лимит ответа API, потоковую обработку и базовую производительность последовательного хранения.

## Требования для E2E

- Python 3.12+ и `playwright==1.57.0`;
- браузеры, установленные через `python -m playwright install --with-deps chromium firefox` (на Linux), либо локальный Chromium в `MAJESTIC_CHROMIUM`;
- Node.js 22 для сборки и основного тестирования; `npm install` проекту не требуется.

```sh
npm run verify
python3 -m pip install playwright==1.57.0
python3 -m playwright install --with-deps chromium firefox
MAJESTIC_E2E_BROWSERS=chromium,firefox MAJESTIC_PLAYWRIGHT_ONLY=1 npm run test:browser
```

GitHub Actions выполняет тесты браузерного DOM отдельным обязательным job `browser-e2e`. Он не включён в `npm run verify`, чтобы офлайн-сборка без Python и браузеров оставалась воспроизводимой.

## Отдельные приёмочные испытания перед публичной публикацией

Автономные фикстуры не являются живыми страницами XenForo. Вручную проверьте установленные расширения в Firefox и Chromium на Majestic RP и Russia Online со своей учётной записью: биндер с обоими редакторами, вкладку профиля, штатное открытие и перемещение тем (только с правами), сроки, уведомления, полное сохранение / восстановление, OAuth с реальным Google аккаунтом. Также отдельно требуются Firefox Android и Safari на соответствующих устройствах. **Эти испытания не подтверждены автоматизированными тестами.**

При работе с внешними сайтами нельзя обходить авторизацию, ограничения или правила их операторов. Тестовые фикстуры не содержат приватной информации пользователей.


## 1.5.3 — Firefox Android runtime permission hotfix

`permissions.request()` вызывается синхронно из делегированного click-обработчика, без ожидания `permissions.contains()` или чтения storage. Регрессионные тесты: `tests/permission-gesture-152.test.mjs`; браузерный DOM-клик проверяется в `tests/browser-e2e.py`. Полное подтверждение требует проверки установленной сборки в Firefox Android с системным окном выдачи прав.
