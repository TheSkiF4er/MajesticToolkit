# MajesticToolkit 1.5.6 — Forum Core

## Что изменилось

- Интеграция с двумя поддерживаемыми форумами разделена на контекст страницы, менеджер редакторов, навигацию и управляемый жизненный цикл. Все модули реально загружаются в content script через существующую регистрацию, новые разрешения не требуются.
- Биндер предлагает только поддерживаемые видимые редакторы сообщений XenForo. При неоднозначности выберите редактор или сфокусируйте нужный. Вставка в выделение/курсор, начало или конец текста; BBCode в textarea, очищенная HTML-разметка в Froala. По возможности используется нативная команда редактирования для Undo, иначе DOM/setRangeText с input-событием. Штатная отправка сообщения остаётся ручной.
- Меню desktop и off-canvas восстанавливается после динамической замены элементов; ссылки не дублируются и удаляются при отключении навигации.
- Раздел «Форум» → «Forum Core · Настройки»: общая конфигурация, отдельные настройки Majestic RP/Russia Online и активного профиля. Иерархия глобальные → форум → профиль. Можно отключить интеграцию, биндер или добавление ссылок, изменить сторону, тему и плотность панели. При включённом наследовании используются вышестоящие настройки. Сброс возвращает наследование или стандартные параметры. Изменения распространяются на открытые вкладки через фоновый процесс.
- Отзыв разрешений приводит к удалению панели и ссылок, остановке наблюдателя, горячих клавиш и сканирования тем. Фоновый процесс дополнительно проверяет разрешение и происхождение запроса. Возврат из BFCache повторно проверяет доступ. Вставка из workspace дополнительно сверяет профиль.

## Обновление

Наложите changed-files ZIP поверх исходников 1.5.5, затем выполните `npm run verify` (Node.js 22). Не удаляйте расширение или его локальное хранилище. Загрузите обновлённую сборку/подпишите её штатным способом и перезагрузите уже открытые вкладки форума: ранее внедрённые скрипты 1.5.5 не поддерживают новый протокол жизненного цикла.

Формат `rpNexusStateV1` и Backup v14 сохранены. Необязательные настройки `preferences.forum` валидируются; старые данные без них работают с прежними значениями по умолчанию. Шаблоны, ссылки, ID профилей и другие модули не мигрируют в новые ключи.

## Проверка и границы

`npm test`, `npm run verify`, Chromium DOM E2E: `MAJESTIC_E2E_BROWSERS=chromium python tests/browser-e2e.py`. CI также проверяет Firefox DOM E2E и AMO lint. Автономные фикстуры не заменяют проверку на авторизованных страницах реальных форумов, Firefox Android и Safari на устройствах. Нативный Undo зависит от браузера/редактора; резервная DOM-вставка не гарантирует штатную историю Undo. Полноценный Binder 2.0, Navigation 2.0 и оформление самого XenForo относятся к следующим релизам.
