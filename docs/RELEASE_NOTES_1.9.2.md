# MajesticToolkit 1.9.2 — Rules & Knowledge AI

## Изменения

- **Рабочий поиск по правилам и источникам**: Workspace → AI Connection → Rules & Knowledge AI. Поиск в Rules Database и Source Library активного профиля и проекта. Правила дополнительно ограничены сервером; архивированные исключены. Исторические редакции и непроверенные пользователем материалы включаются только по выбору пользователя.
- **Цитаты и редакции**: карточки показывают название, ID редакции, дату, статус ручной проверки и рабочую HTTPS-ссылку на оригинал. Контрольные суммы SHA-256 источников проверяются перед передачей. Формулировки и допустимые альтернативы санкций извлекаются из действующих сохранённых записей, а не генерируются из предположений.
- **Privacy by design**: пользователь выбирает до пяти фрагментов, видит полный JSON тела запроса и отдельно подтверждает передачу. Перед отправкой повторно проверяются состояние профиля, выбранные редакции, текст, ссылки и настройки AI. Данные жалоб, заметки, файлы, токены и невыбранные записи не передаются.
- **OpenAI Responses API**: существующий реальный локальный шлюз обрабатывает `mode: rules` с валидируемыми полями, ограничением размеров, контекстом, который считается недоверенными данными, и требованием нумерованных ссылок. Потоковый ответ и отмена работают через прежний клиент. Никакие ссылки в ответе модели не становятся автоматически ссылками интерфейса.
- **Интеграция**: переход в AI из карточки правила и импортированной статьи; существующий обычный AI-чат, локальный офлайн-помощник, Backup v17 и четыре платформенные сборки сохранены.

## Проверка и эксплуатация

Запустить `npm run verify` и `npm run test:browser`. Для фактической работы требуется отдельный ключ OpenAI на локальном шлюзе 1.9.1 и его токен в открытом Workspace. Node HTTP-тесты используют настоящий протокол шлюза с имитацией ответа OpenAI и не создают оплачиваемых запросов. Chromium E2E — автономные WebExtension-фикстуры. Продакшен-приёмка на настоящих авторизованных форумах и физических устройствах не выполнена.

**Безопасность:** модель может ошибаться даже при наличии ссылок; пользователь должен самостоятельно проверить текст, применимость и санкции. Исторические источники могут быть устаревшими. Ни результаты модели, ни введённые запросы не изменяют локальные правила, жалобы, решения или исходные тексты и не публикуются автоматически.
