# MajesticToolkit 1.8.2 — Временная шкала доказательств
> **Архив релиза.** Здесь сохранены возможности, проверки и ограничения, актуальные на момент выпуска 1.8.2. Полная последовательность изменений — в [истории версий](../CHANGELOG.md).


## Рабочий функционал

В **Workspace → Жалобы → Таймлайн** (кнопка у каждой жалобы) реализован редактор локальной хронологии. Добавьте событие, укажите известную дату и время события либо оставьте его неизвестным, опишите участников и обстоятельства. Можно связать несколько доказательств жалобы и дополнительно выбрать видеодоказательство с началом/концом интервала в секундах. Изображения/документы доступны через существующий Evidence Vault.

События отображаются в хронологическом порядке. Смена статуса «не проверено» / «подтверждено пользователем» / «оспаривается» не выдаёт официальных выводов. Кнопка материала открывает HTTPS-видео с таймкодом; локальные MP4/WebM воспроизводятся после проверки SHA-256 с переходом к началу и остановкой на конце. Другие локальные файлы скачиваются после проверки целостности.

Операции выполняются через доверенный фоновый процесс расширения с проверкой активного профиля, проекта, ссылок на доказательства и актуальной даты изменения дела. Удаление доказательства с активными связями таймлайна отклоняется; сперва измените соответствующие события. Если дело завершено, откройте его заново перед изменениями. При изменении хронологии текущий расчёт санкций становится черновиком и требует повторной проверки, чтобы старое решение не использовало новые факты без контроля.

## Хранение и перенос

Существующие жалобы 1.8.1 с отсутствующим полем `timeline` автоматически читаются с пустой хронологией. События являются частью обычной записи жалобы и входят в **Backup v16** с проверкой ссылочной целостности. Лимит — 120 событий и 48 000 символов сериализованных данных на дело. Видео-таймкоды ограничены 0–86 400 секундами. **Бинарные вложения IndexedDB не включены в JSON Backup v16**; перед переносом скачайте их отдельно.

## Безопасность и ограничения

Даты событий и статусы устанавливает пользователь; расширение не определяет виновность, не загружает внешние видео по ссылке, не записывает экран и не публикует решения автоматически. Внешние проигрыватели могут не поддерживать конкретный способ передачи таймкода. При наличии большого количества событий итоговый текст решения может превысить существующий лимит черновика, в этом случае его необходимо сократить.

## Проверка

Запуск: `npm run verify`, затем `npm run test:browser`. В браузере проверены операции интерфейса на автономных XenForo-фикстурах с имитацией WebExtension API; воспроизведение настоящего локального видео на устройствах Firefox Android/Safari требует отдельной проверки. GitHub Release публикуется только workflow репозитория.
