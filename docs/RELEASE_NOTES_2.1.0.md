# MajesticToolkit 2.1.0 — Government & Justice GA

## Рабочие сценарии

Откройте `#justice` → «Обзор»: список действий содержит реальные дела из Government Store выбранного RP-профиля. Показаны просроченные/сегодняшние/ближайшие сроки (7 дней), ожидающие ходатайства, назначенные на ближайшие 7 дней или просроченные заседания, апелляции на рассмотрении и завершённые дела без утверждённого судебного решения. Нажатие «Открыть дело» открывает подлинную карточку. Никакая задача не назначается автоматически и не отправляется в сеть.

## Проверка целостности

В «Обзор» нажмите «Проверить данные». Программа читает Government Store, Document Studio и список Evidence Vault; проверяет профили, подсудность и ссылки между делами и документами, SHA-256 утверждённых редакций и судебных решений, метаданные судебных доказательств и физическое наличие/хеш локальных файлов, прикреплённых к делу. При повреждении показывается ошибка, оригинальные записи не перезаписываются.

## Backup v19 / восстановление

- Экспорт JSON v19 перед сохранением проверяет связность судебных записей и SHA-256 утверждений. JSON сохраняет метаданные Vault, но не бинарные файлы.
- Переносимый ZIP v19 сохраняет бинарные файлы Vault и проверяет SHA-256 каждого перед упаковкой. Импорт ZIP проверяет контрольные суммы и полный перечень вложений до применения к хранилищам.
- Импорт JSON v1–v19 совместим с предыдущими версиями. Перед подтверждением и записью выполняется проверка судебных связей и утверждений для имеющихся в копии записей. Для старых форматов отсутствующие подсистемы остаются в прежнем состоянии, как и ранее.
- История AI экспортируется только при установленном флажке. Токены, разрешения и сетевое согласие не переносятся; включение AI требуется повторно.

## Лимиты / безопасность

Это автономное локальное браузерное расширение, без серверной синхронизации судей и многопользовательских ACL. SHA-256 служит контролем целостности, а не цифровой подписью или подтверждением юридической силы. Реальные RP-регламенты и судебная компетенция требуют ручной проверки.

## Release checks

`npm run verify`; дополнительно `npm run test:browser:decisions`, `npm run test:browser:evidence`, `npm run test:browser:procedural`, `npm run test:browser`. Сквозные сценарии используют локальную тестовую фикстуру, не подключение к игровому серверу.
