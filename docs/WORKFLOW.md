# Complaint Workflow 1.4.0

## Использование

1. Откройте **Жалобы**, добавьте ссылку на существующую тему XenForo Majestic RP либо Russia Online. Данные хранятся только внутри расширения.
2. В строке жалобы нажмите **Этапы / журнал** (тот же блок доступен при выборе «Черновик» и «Доказательства»).
3. Отметьте выполнение проверки на текущем этапе: регистрация темы → изучение обстоятельств → проверка доказательств → подготовка решения. Галочки означают ручное подтверждение; программа не устанавливает факты самостоятельно.
4. Нажмите **Следующий этап**. Переход не разрешается, пока текущий пункт не подтверждён. Кнопка **Назад** возвращает к предыдущему этапу и сохраняет журнал.
5. В выпадающем списке выберите тип проекта решения. Нажмите **Создать черновик решения**. Если существующий черновик заполнен, для замены требуется отдельное подтверждение. Дозаполните факты, положения игровых правил и итог вручную.
6. Завершение последнего этапа возможно только с сохранённым черновиком, отмеченной проверкой и явным подтверждением. После завершения статус жалобы становится **Завершена**. Возврат с этого этапа переводит её обратно в работу.
7. Для пояснения к решению используйте поле «Запись в журнале». Изменение статуса, срока, черновика, доказательств, контрольных отметок и этапов фиксируется локально. Можно скопировать журнал в буфер обмена.

## Проверки сроков

Фоновый процесс проверяет активные жалобы по будильнику браузерного расширения приблизительно каждые пять минут. Отдельные уведомления предусмотрены за 24 часа, 1 час, 15 минут и по истечении срока. Для каждого уровня предупреждения и даты действует защита от дублирования; при изменении срока цикл начинается заново. Для закрытых жалоб уведомления не отправляются. С закрытым браузером проверки не выполняются.

## Данные, резервные копии и безопасность

Новые поля `workflow` (этап, чек-лист, тип решения, последние 120 событий) хранятся в исходных записях жалоб `rpnComplaintV3:*`; новые разрешения и удалённые сервисы не требуются. Существующие жалобы мигрируют при чтении. Для ранее закрытых жалоб сохраняется их завершённый статус.

Новый JSON-экспорт **v13** включает журнал и процесс рассмотрения. Импорт предыдущих копий v1–v12 сохраняет совместимость и проверяет привязку к профилям. До импорта создаётся точка восстановления SHA-256. OAuth-токены в копии не входят.

Генератор решений **не делает правовой оценки**, не проверяет обоснованность санкций и не публикует текст на форумах. Все действия модерации и размещение ответов выполняет пользователь через штатные интерфейсы XenForo.
