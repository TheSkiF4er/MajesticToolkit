# MajesticToolkit 1.5.4 — Forum & Fletcher Wiki sources, Server Monitor

## Изменения

- Быстрый доступ: официальный сайт Russia Online `https://russia.online/`.
- Источники для Поиска и локального помощника: по явной команде можно импортировать текст уже открытой темы официального форума Majestic RP или Russia Online. Сохранённые выдержки индексируются локально и сопровождаются ссылкой на первоисточник.
- Центр знаний: аналогичный ручной импорт доступной статьи Fletcher Wiki. Отдельное разрешение для `fletcher-wiki.com`/`www.fletcher-wiki.com` запрашивается непосредственно при нажатии; содержимое страницы антибот-проверки не импортируется. Сохранённые статьи могут участвовать в связях Центра знаний, а их текст — в локальном поиске.
- Сохранение пользовательских ссылок XenForo перехватывается обработчиком `submit` на фазе capture, через DOM-атрибут `id` (поле формы `name=id` не должно запускать обычную HTML-навигацию).
- Server Monitor поддерживает несколько явных форматов числовых счётчиков официального API, резервный `https://api.majestic-files.net/meta/servers` при отдельном разрешении. Если официальные источники недоступны, отображается причина, не выдуманный онлайн.
- Резервные копии v14 сохраняют ручные выдержки; старые копии не удаляют уже импортированные тексты автоматически.

## Приёмка

- `npm run verify`: Node.js 22.x, все автоматические тесты, сборки и SHA-256.
- `python tests/browser-e2e.py`: автономные Chromium DOM-сценарии XenForo.
- Перед публичным релизом проверяйте на реальных форумах, Firefox Android и Safari. Отдельно проверьте возможность доступа к конкретной статье Fletcher Wiki без обхода браузерной защиты и наличие живого ответа источников онлайна. Автоматические тесты не гарантируют доступность внешних сайтов.

В манифесты добавлены только **необязательные** host permissions для Fletcher Wiki и резервного официального API. Нового backend и автоматического обхода страниц нет.
