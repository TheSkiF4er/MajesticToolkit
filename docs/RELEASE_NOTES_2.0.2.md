# MajesticToolkit 2.0.2 — Law Codex Advanced

**Установка патча:** распаковать ZIP поверх полного проекта **2.0.1**, сохраняя относительные пути. Патч — только изменённые файлы. Затем выполнить `npm test`, `npm run build` и установить сборку из `dist/<browser>`.

## Реализовано

- Реальный поиск применимой редакции **на дату события**: интервалы `[effectiveDate, expiresAt)`, вступление новых редакций, возможные пробелы в действии, отмена всего акта с `repealedAt`. Ручное переключение рабочей редакции не меняет историю действия закона.
- При импорте текстов распознаются `Раздел …`, `Глава …`, `Статья …`; преамбула, текст и нумерованные части/пункты сохраняются. Поиск теперь учитывает структуру, категорию, дату и действующий профиль.
- Создание поправок с причиной, датой вступления и возможным окончанием действия. История версий неизменяема; сравнение двух версий показывает изменённые, добавленные и удалённые статьи и их нумерованные пункты (с сопоставлением «было / стало»).
- Ссылка на исходный нормативный текст **закрепляется за каждой новой редакцией**. Есть явная, отменяемая отметка «проверено пользователем» с датой. Автоматического подтверждения официальности или правовой силы источника нет. Старые редакции без закреплённой ссылки нельзя отметать как сверенные, чтобы не подменять исторический источник текущим.
- Копирование статьи и цитаты со снимком её редакции, исходным текстом и SHA-256. SHA-256 — контроль целостности текстового снимка, **не электронная подпись, не нотариальное удостоверение и не юридическая экспертиза**.
- Экспорт Law Codex v2: JSON + SHA-256 по исходному набору записей. Импорт проверяет хеш до записи в хранилище и отказывает при подмене; старый JSON v1 остаётся импортируемым без претензии на проверенный хеш.
- Ведомственные решения Government Tools сохраняют источник именно выбранной редакции, если он закреплён; уже принятые решения по-прежнему сохраняют собственные текстовые снимки статей.
- Правила профилей, исходные локальные ключи `majesticLawV5:*`, существующие ссылки из решений и документов, а также Backup v18 остаются совместимы. Новая схема глобальной резервной копии не требуется: дополнительные метаданные находятся в прежних записях Law Codex.

## Границы релиза

Законодательные акты загружаются и проверяются самим пользователем. Автоматическая загрузка действующих законов с сайтов RP-проектов, официальная верификация и внешний сервер общего судебного делопроизводства **не реализованы**. Редакции из старого формата v1 не имеют закреплённого per-edition источника: интерфейс явно указывает на этот факт.

## Проверка

- `npm test` — хранение, миграции, редакции, датирование, межпрофильная изоляция, хеширование, изменения и import/export.
- `npm run build` — Chromium, Firefox, Firefox Android и Safari.
- `python3 tests/browser-e2e.py` — сценарии работы с реальными DOM-контролами Law Codex через Government & Justice.
