# MajesticToolkit 2.1.4 — Families & Membership

## Реализовано

- **Рабочий реестр семей:** `#economy` → «Семьи и игроки». Создание, редактирование названия/тега/описания, поиск по семье и игрокам, архивирование и восстановление.
- **Ранги:** два начальных ранга («Глава», «Участник»), добавление и редактирование рангов, приоритеты и запрет удаления используемого ранга. Нельзя оставить семью без рангов.
- **Составы:** вступление участника с никнеймом, рангом и датой, изменение ранга и выход. Сохраняются активные и бывшие участники; одновременный дубликат никнейма в одной семье запрещён.
- **История:** каждое изменение дополняет последовательность верифицируемых событий с временем и причиной. Участники с историей не удаляются «без следа»; семья с кадровой историей архивируется, а не удаляется. История локальная, не заверенная внешним сервером.
- **Статистика:** сохранённые матчи `match` группируются по точному названию семьи или по историческому имени, добавленному вручную. Все старые поля матча остаются нетронутыми. Семейные показатели (матчи, победы, урон, K/D, Win Rate) вычисляются из действительных записей.
- **Экспорт CSV состава:** участник, текущий ранг, вступление/выход; защита от CSV-формул.
- **Профили и целостность:** семьи и события проверяются при каждой операции чтения/записи; чужие профили, повторяющиеся имена/псевдонимы, конфликтующие участники и удаление зависимых записей блокируются. Последовательные операции поддерживают Web Locks при наличии.
- **Backup v19:** добавлено необязательное поле `families`. Экспорт валидирует данные и профиль; импорт проверяет перед записью, откатывает ошибки; устаревшие копии без `families` сохраняют текущие семьи, если отсутствующие в копии профили не приведут к их потере.

## Размещение данных и ограничения

Данные хранятся только локально (`browser.storage.local`, префикс `mtFamiliesV214:`). Нет получения сведений о членстве из Majestic RP, серверной синхронизации, контроля игровых полномочий или автоматического сопоставления разных названий. Семейные владельцы складского имущества 2.1.3 пока представлены существующими текстовыми значениями; их миграция и реестр организаций относятся к следующим релизам.

## Проверка и установка

1. Распаковать **только изменённые файлы** поверх полного проекта 2.1.3.
2. Выполнить `npm run verify` для модульных тестов, четырёх браузерных сборок, проверки синтаксиса и релизных архивов.
3. Выполнить `npm run test:browser:families`, затем `npm run test:browser:inventory`, `npm run test:browser:marketplace` и `npm run test:browser:economy`.
4. Проверить регистрацию семьи, рангов, состава, историю, привязку старого матча, CSV и перенос Backup v19 в изолированном RP-профиле.

Проверки Playwright проводятся на локальной браузерной фикстуре, не в рабочем аккаунте Majestic RP.
