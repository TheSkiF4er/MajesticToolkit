# MajesticToolkit 2.2.0 — Economy & Crime GA

Дата: 2026-11-19. Обновление с полной версии 2.1.9: заменить изменённые файлы и выполнить `npm run verify`.

## Реальные изменения

1. Обзор Economy & Crime содержит **живую проверку всех RP-профилей**. Кнопка «Проверить все RP-профили» загружает сохранённые данные, выполняет строгую валидацию восьми реестров, проверяет существование родителей и ссылок на документы и доказательства, выводит счётчики и ошибки с указанием проблемной подсистемы. Уровень повреждения не замаскирован зелёным индикатором, если часть хранилища недоступна.
2. Исторические `deal`, `cash` и `match` раньше отображались с пропуском повреждённых записей. Для Backup v20 и добавления записей введено строгое чтение ключей, идентификаторов и сумм; экспорт прерывается при повреждении с сообщением, чтобы не создавать неполную копию.
3. При расчёте месячного бюджета действующие расходы индексируются один раз по счёту, месяцу и категории. Сохранено прежнее поведение при регистре букв, отмене операций, переполнениях и превышении лимитов.
4. Обновлены версия четырёх браузерных манифестов, имя выходного файла резервной копии, release CI и полный набор браузерных проверок прошлых подсистем.

## Проверка

- `npm run verify` — Node.js, четыре сборки, SHA-256 архивов.
- `npm run test:browser:economy-ga` — создание реальных рыночных записей, диагностика в Chromium, повреждение старой записи, запрет выгрузки Backup, устранение ошибки, повреждение/исправление ссылки Evidence Vault и итоговый экспорт Backup v20.
- `npm run test:browser:eco-integrations`, `npm run test:browser:finance`, `npm run test:browser:analytics` — регрессии смежных модулей.

## Границы проверок

Локальные тесты используют браузерные фикстуры и реальные операции хранилища. Они не удостоверяют работу на действующем RP-сервере, регистрацию расширения в магазинах, кроссбраузерное UI-тестирование четырёх установленных расширений или сетевую синхронизацию. Существующие независимые денежные источники не суммируются автоматически во избежание двойного учёта. Backup v20 сохраняет старый формат данных, так что миграция не нужна.
