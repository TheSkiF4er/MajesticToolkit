# MajesticToolkit 1.9.5 — ИИ и продуктивность
> **Архив релиза.** Здесь сохранены возможности, проверки и ограничения, актуальные на момент выпуска 1.9.5. Полная последовательность изменений — в [истории версий](../CHANGELOG.md).


## Рабочие функции

- Единый AI Workspace с переключением «Чат», «Правила», «Жалобы», «Поддержка», «Контексты и черновики»; все существующие рабочие AI-модули сохраняют функциональность.
- Общий многоходовой чат: до шести последних реплик передаются в OpenAI Responses API через локальный Gateway как структурированные сообщения. Полный вопрос, дополнительные контексты и передаваемая история отображаются до отправки; отдельное согласие требуется на каждый запрос. Никаких автоматических запросов при переключении модулей.
- До 20 локально сохранённых диалогов, 30 контекстных ссылок и 30 черновиков на профиль. Сохранение только через явные кнопки. Удаление, повторное открытие и продолжение диалога; токен шлюза никогда не сохраняется в AI Workspace.
- Контекст можно выбрать из Rules Database, Source Library или Complaint Manager. До отправки заново проверяется принадлежность профилю и актуальность выбранного текста; для импортированных источников проверяется SHA-256. По умолчанию не добавляются внутренние заметки, никнеймы и доказательства.
- Редактирование AI-черновика, локальное сохранение и ручное создание действующего шаблона Binder 2.0 через `upsertTemplate`. Нет автоматической публикации сообщений или изменения санкций.
- Локальный режим Productivity доступен даже без AI, сохранилась поддержка OpenAI Gateway 1.9.1 и режимов 1.9.2–1.9.4.

## Приватность и Backup

История и контексты хранятся отдельно в `storage.local` (`mtAiWorkspaceV195:<profileId>`), не включаются в JSON/ZIP Backup v17 и удаляются при удалении профиля. Ключ OpenAI находится исключительно в окружении шлюза, токен шлюза хранится в памяти страницы. Пользователь должен самостоятельно сохранить/удалить нужную историю до удаления расширения. Созданные из AI-черновиков шаблоны Binder относятся к обычным локальным данным и входят в резервные копии.

## Проверка и границы

`npm run verify`, `npm run test:browser`, отдельные тесты AI Workspace и Gateway. Тесты использовали локальную имитацию OpenAI Responses SSE, не платные запросы к API. Сборки Chromium, Firefox, Firefox Android и Safari проверены на уровне исходников, манифестов и ZIP. Для реальной эксплуатации необходим настроенный локальный шлюз с собственным ключом OpenAI. Реальные авторизованные форумы и физические устройства не охвачены тестами.

## Установка

Примените исходный ZIP-патч поверх полных исходников 1.9.4; запустите `npm run verify` и обновите расширение из `dist/`. Для облачного AI используйте `npm run ai:gateway` с настроенными `OPENAI_API_KEY` и `MT_AI_GATEWAY_TOKEN`.
