# Воспроизводимый выпуск и публикация

## Локальные release gates

```sh
node --version # Node 22.x
npm run verify
cd release && sha256sum -c SHA256SUMS
```

Команда создаёт `release/MajesticToolkit-1.1.0-{chromium,firefox,firefox-android,safari}.zip`, а также `release-manifest.json`, `SHA256SUMS`. Сборка не использует сеть или удалённые скрипты. `scripts/check-release.mjs` проверяет контрольные суммы, имена файлов и совпадение каждого извлечённого файла с `dist/`.

## Предрелизные приёмочные испытания (обязательны для публичного статуса Stable)

- Установить Chromium-сборку в актуальные Chrome и Edge, проверить запуск/перезапуск Service Worker и popup/sidebar/workspace.
- Установить подписанное Firefox-дополнение, проверить темы, редактор и шаблоны на текущем XenForo.
- Пройти все действия: профиль → форум → жалоба → видео → Law → решение → документ → PDF; выполнить backup/import/rollback при отключении браузера.
- Проверить Android Firefox отдельно на физическом устройстве и читаемость всех форм на узких экранах.
- Собрать Safari App Extension средствами Apple; проверить на macOS и при необходимости iOS/iPadOS.
- Провести тестирование Google OAuth с зарегистрированным клиентом и Google Docs/Sheets/Drive в реальном аккаунте.
- Проверить отсутствие ошибок/утечек данных между профилями и выполнение действий только при наличии прав форума.

**Эти проверки не считаются выполненными от того, что прошли unit-тесты.** Стабильный релиз нельзя считать полностью подтверждённым до их прохождения.

## Публикация

Проверка с Mozilla Add-ons Linter выполняется в GitHub Actions (`addons-linter@10.14.0`) после `npm run verify`. Без доступа к npm в локальной среде результат этого отдельного lint-гейта не подтверждён. См. [AMO_SUBMISSION.md](AMO_SUBMISSION.md).


- Chrome Web Store: создать аккаунт разработчика, загрузить `chromium.zip`, предоставить privacy disclosure, скриншоты и пройти review.
- Mozilla AMO: проверить стабильный Gecko ID, подписать `firefox.zip` через AMO; отдельно подготовить листинг для Android, если совместимость подтверждена.
- Edge Add-ons: отдельный листинг и review с Chromium-пакетом.
- Safari: собрать `.app` через инструменты Apple, подписать, пройти проверку App Store.
- GitHub: после проверки репозитория создать tag `v1.1.0`, прикрепить пакеты и `SHA256SUMS`. Публикация/подпись не выполнена этим ZIP-патчем.

## Обновление проекта

Применяйте архив `MajesticToolkit-1.1.0-changed-files.zip` поверх исходников предоставленной базы. Внутри только новые и изменённые файлы. Если файл удалён в новых версиях, инструкции будут в `PATCH_DELETE.txt` (в этой версии удаляемых исходников нет). После обновления запустите `npm run verify`.
