# MajesticToolkit 1.6.4 — Калькулятор наказаний
> **Архив релиза.** Здесь сохранены возможности, проверки и ограничения, актуальные на момент выпуска 1.6.4. Полная последовательность изменений — в [истории версий](../CHANGELOG.md).


Откройте «Правила проекта» → «Калькулятор наказаний» или «Калькулятор ↗» в оверлее (Alt+Shift+P). Выберите участника, ID, правило и допустимую санкцию. При переходе из темы доступен её локальный черновик. Условия применения необходимо проверить вручную.

- Отдельный расчёт для каждого участника; 20 участников, 40 санкций на участника, 200 всего. Повтор одного варианта запрещён; совместимость нескольких вариантов одного правила требует явного подтверждения.
- Ручной режим по умолчанию. Пользовательская или проверенная пользователем политика с источником: сумма, максимум, пределы по типу и единице. Разные единицы не объединяются автоматически. Ban и HardBan требуют отдельного решения.
- Опциональное явно заданное преобразование Demorgan → Ban: при M ≥ порога результат = базовые дни + floor((M − порог) / шаг) × дни за шаг. Порядок: объединение, преобразование, пределы. Это пользовательская формула, а не восстановленный алгоритм legacy calcSettings.
- Сохраняются выбранные редакции, источники, значения, политика и шаги; история до 20 расчётов на профиль/проект/сервер. Экспорт истории отдельным JSON, удаление и создание копии. Backup v15 остаётся совместимым, история и политика калькулятора в него пока не входят.
- Расчёт предварительный; публикация и выдача наказания не автоматизируются. Реальные правила необходимо сверять с источниками.

Проверки: `npm run verify`, `npm run test:browser`.
