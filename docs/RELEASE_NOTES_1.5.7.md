# MajesticToolkit 1.5.7 — Биндер 2.0
> **Архив релиза.** Здесь сохранены возможности, проверки и ограничения, актуальные на момент выпуска 1.5.7. Полная последовательность изменений — в [истории версий](../CHANGELOG.md).


Обновление с 1.5.6. В рабочем пространстве откройте «Форум». Библиотека поддерживает вложенные папки (`Жалобы/Ответы`), теги, ручной порядок (меньшее число выше), избранное, недавние, дублирование, массовый перенос и удаление. История использования хранится отдельно по профилям; глобальные шаблоны видны всем профилям. Сохранённые шаблоны и их метаданные входят в Backup v14. Черновик сохраняется в sessionStorage вкладки до явного сохранения.

## Конструктор и применение

Добавьте `{{decision}}` в текст и настройте тип поля: текст, многострочный, число, дата, URL, список, Да/Нет. Для обязательного поля вставка без значения запрещена. Значения проходят проверку; квадратные скобки в значениях BBCode заменяются полноширинными во избежание внедрения тегов. Стандартные поля `server`, `project`, `thread`, `url`, `date`, `time`, `selection`, `nickname`, `reason` используют контекст или поля панели. История хранит до 10 сохранённых редакций. Неподдерживаемая разметка остаётся текстом. Для работы на форуме разрешите доступ к домену, обновите страницу и нажмите MT или Alt+Shift+B. Alt+Shift+1…9 сохраняют назначение, конфликты слотов в одном профиле блокируются. Для пользовательских переменных появляется форма и кнопка предпросмотра. Отправка сообщения всегда вручную.

## Импорт

«Экспорт набора» создаёт JSON `majestic-binder-pack` с шаблонами и ссылками активного профиля. «Импорт набора» показывает содержимое, целевой профиль и варианты пропуска, замены либо создания копий. Поддерживается формат `binds_and_links.json` (`binds`, `bindFolders`, `customLinks`): текст и папки переносятся, пустые текстовые бинды с данными наказаний превращаются в справочный текст с диапазонами и ссылкой. Настройки калькулятора и автоматическое применение наказаний не импортируются. Все ссылки HTTPS, неизвестные поля не исполняются. Перед массовыми изменениями сохраняется точка восстановления в «Резервные копии». Конфликтующий слот снимается у импортируемой записи. Лимиты: 500 шаблонов, 60 ссылок, файл 8 МиБ. Импорт оригинального предоставленного JSON проверен отдельно (71 шаблон, 2 ссылки).

## Проверка

`npm run verify` — тесты, сборки, проверка исходников и ZIP; `npm run test:browser` — Chromium DOM E2E на автономных XenForo-фикстурах. Для Firefox: `MAJESTIC_E2E_BROWSERS=chromium,firefox python tests/browser-e2e.py` после установки Playwright. Реальные авторизованные страницы и Safari/Android на устройствах требуют отдельной приёмки.
