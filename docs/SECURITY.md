# Безопасность

## Модель доверия

Локальные форумы и видеосайты считаются недоверенным содержимым. Контентные скрипты не имеют доступа ко всей базе: `RP_NEXUS_FORUM_DATA` выдаёт только шаблоны текущего профиля и краткие метаданные профиля, `RP_NEXUS_VIDEO_CASES` выдаёт только ID и заголовки жалоб. Фоновый процесс проверяет источник сообщения перед выполнением действий. Прямое редактирование чужих записей и обход прав сайта недопустимы.

## Разрешения

Host permissions заявлены как optional для выбранных форумов, видео и Google API. Не добавляйте wildcard-доступ `<all_urls>` или небезопасную CSP. Скрипты должны быть частью пакета: загрузка исполняемого кода с удалённых серверов в MV3 запрещена.

## Локальные данные

Браузерное хранилище не шифруется на уровне приложения. Используйте защиту профиля ОС, резервные копии храните отдельно. OAuth-токены не включаются в локальные снимки восстановления и JSON-резервные копии. SHA-256 снимка проверяет случайные повреждения, но не защищает от злоумышленника с правом изменять само локальное хранилище и его контрольную сумму.

## Отчёты об уязвимостях

Не публикуйте в issues OAuth-токены, документы с персональными сведениями, записи жалоб или резервные копии. Для приватного раскрытия используйте GitHub Security Advisories соответствующего репозитория, если они включены.

## Непроверенные области

Не проводились внешний пен-тест, review магазинов, реальная авторизация Google и сквозное тестирование модераторских операций на действующих сайтах. Не заявляйте выполнение этих шагов без результатов.
