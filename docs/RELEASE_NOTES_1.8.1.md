# MajesticToolkit 1.8.1 — Evidence Vault 2.0

Релиз на основе 1.8.0. Реальная локальная медиатека доказательств в IndexedDB для рабочего пространства расширения.

## Рабочие возможности

- Загрузка файлов по действию пользователя в IndexedDB расширения (PNG, JPEG, WebP, GIF, PDF, TXT, MP4, WebM, DOCX, XLSX) с проверкой сигнатуры контейнера и контрольной суммой SHA-256 (`crypto.subtle` в защищённом origin расширения). Файл не передаётся на внешние серверы.
- Локальная библиотека файлов и HTTPS-ссылок с названием, комментарием, таймкодом, именем файла, размером, MIME, SHA-256 и датой добавления. Поиск, изменение названия/заметок, предпросмотр изображений, видео и текста, безопасное скачивание после проверки целостности, удаление с проверкой используемых связей.
- Прикрепление существующего материала к конкретной жалобе с фоновым подтверждением профиля и SHA-256; в жалобе хранится стабильный `vaultId` и снимок метаданных. Варианты санкций, старые ID доказательств и история расчётов сохраняются.
- Миграция старых HTTPS-ссылок из жалоб по подтверждению пользователя без замены ID и таймкодов; новые материалы доступны для повторного использования внутри профиля.
- Защита от удаления материала, если он используется в жалобе или зарегистрированном решении. При удалении профиля его медиатека очищается после успешной операции с профилем.
- Регистрационные отчёты и шаблоны решений показывают хеш локальных файлов вместо выдуманной внешней ссылки; доступно совместимое хранение ссылок в Backup v16.

## Ограничения

- Бинарные вложения IndexedDB **не включены** в стандартный JSON Backup v16 или точку восстановления `storage.local`. Скачайте файлы отдельно перед переносом, очисткой данных или удалением расширения. Пакетный экспорт/импорт самих файлов запланирован на 1.8.5.
- Максимум 32 МиБ на файл, 256 МиБ на медиатеку установки, 250 записей на профиль. Фактическая доступность места зависит от браузера; QuotaExceededError выводится пользователю. Нет скрытой записи видео, скачивания контента по ссылке или автоматического определения виновности.
- Реальный IndexedDB на установленном расширении необходимо проверить на целевых устройствах. Chromium E2E использует имитацию IndexedDB, поскольку из данной тестовой среды переходы на HTTP(S)/localhost/file запрещены. Сборки Firefox/Firefox Android/Safari проверяются статически; тесты на устройствах не проводились.

## Установка и QA

Распаковать патч поверх 1.8.0, `npm run verify`, затем `npm run test:browser`. Сборка формирует четыре пакета с проверкой SHA-256. GitHub Release создаётся только после выполнения workflow в репозитории.
