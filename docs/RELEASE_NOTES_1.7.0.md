# MajesticToolkit 1.7.0 — Rules & Punishments

Финальный релиз цикла Rules & Punishments (1.6.1–1.6.5).

## Рабочий процесс

1. Откройте «Правила и наказания» в Workspace. Вкладка «Обзор» показывает фактические правила, проверенные редакции, импортированные бинды, черновики тем, историю расчётов и открытые жалобы активного профиля.
2. На вкладке «База и наборы» создайте правило или откройте импортированный набор. Импорт `binds_and_links.json` остаётся доступен через «Форум → Биндер → Импорт набора». Повторно импортировать уже сохранённые записи не требуется.
3. В карточке активной редакции нажмите «Выбрать в калькуляторе». Вкладка «Калькулятор и дела» сохраняет текущие поля при переходах между вкладками раздела; выберите участника, санкцию и срок, настройте явную политику, рассчитайте и сохраните результат.
4. Для конкретной жалобы откройте её из «Продолжить рассмотрение» на обзоре, из Complaint Manager или из форумного оверлея. Привяжите доказательства, сохраните черновик или расчёт, подготовьте решение через Binder 2.0. Вставка — только в соответствующую тему и после подтверждения. Публикация вручную.
5. На Dashboard доступны три новых настраиваемых виджета: избранные правила, незавершённые рассмотрения, недавно открытые нарушения. Старый порядок и скрытые виджеты сохраняются; для прежних настроек новые виджеты первоначально скрыты.

## Данные и совместимость

- Backup v15 расширен дополнительным полем `punishments`: политики и исторические снимки калькулятора по профилю/проекту/серверу, черновики оверлея по темам. Правила и рассмотрения жалоб сохраняются по прежней схеме. Экспорт включает существующие записи калькулятора для других серверов того же профиля и проекта.
- Снимки истории не пересчитываются на основе текущих редакций. Импорт проверяет структуру, лимиты, область действия и источники. Черновики могут ссылаться на старые редакции — перед новым расчётом действует существующая проверка актуальности.
- Копии v1–v15, в которых нет нового поля, не заменяют существующие данные наказаний при совместимых профилях. Полные копии 1.7 заменяют экспортированные хранилища наказаний. При несовместимых профилях восстановление старой копии отклоняется до изменения данных.
- Точка восстановления включает локальные ключи калькулятора и черновиков. Сохраняются существующие ограничения: 48 МиБ на JSON-копию, 20 МиБ на точку восстановления, 16 МиБ на совокупные данные наказаний в копии; до 20 расчётов/2 МиБ истории на комбинацию профиля и сервера.
- Формулы и правила из импортированного файла не объявляются официально подтверждёнными. `calcSettings` сохраняются без автоматической активации неизвестной формулы. Новых разрешений браузера или внешних сервисов нет.

## Проверка

`npm run verify` — модульные тесты, четыре сборки, проверка синтаксиса/манифестов, ZIP и SHA-256.

`npm run test:browser` — Chromium DOM E2E на автономных фикстурах XenForo и имитации WebExtension API. Реальные авторизованные страницы, подписанная установка Safari и мобильные устройства требуют отдельной проверки.
