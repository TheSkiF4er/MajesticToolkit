# MajesticToolkit 1.7.4 — Дополнительные инструменты модерации
> **Архив релиза.** Здесь сохранены возможности, проверки и ограничения, актуальные на момент выпуска 1.7.4. Полная последовательность изменений — в [истории версий](../CHANGELOG.md).


## Использование

- Откройте поддерживаемую тему XenForo и вкладку MT → Модерация. «Показать доступные действия» открывает штатное меню, если оно есть. Доступные элементы отображаются только при распознавании. Поддерживаются закрытие/открытие, перенос, закрепление/открепление и редактор заголовка/префикса темы.
- Подтвердите конкретное действие. Некоторые штатные элементы могут выполнить операцию немедленно; остальные откроют форму. Toolkit не формирует административных запросов и не считает открытие формы доказательством успеха. Намерение сохраняется в журнале существующей жалобы; наблюдаемое состояние темы проверяется отдельно.
- В Workspace → Жалобы выберите до 100 записей и нажмите «Создать очередь модерации». Открывайте темы, переходите к рассмотрению и сохраняйте индивидуальные проверенные решения. Вставка требует открытой точной темы и редактора, подтверждения и актуального расчёта. Отправка только вручную.
- Состояние очереди сохраняется по профилям и в Backup v15. Отметка обработки не означает подтверждённой публикации/выдачи наказания. Пропущенные/обработанные дела можно вернуть в очередь.

## Ограничения

Новые действия распознаются по видимым штатным ссылкам XenForo с точным ID темы; нестандартные маршруты и скрытые/неоднозначные действия не поддерживаются. Удаление, восстановление и модерация отдельных сообщений не добавлены. Нет автоматических массовых серверных операций. Реальные авторизованные форумы необходимо проверить отдельно.
