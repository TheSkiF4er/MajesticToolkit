# Воспроизводимая сборка для Mozilla Add-ons

**Версия 2.4.0 · Руководство для разработчика и проверяющего Mozilla**

MajesticToolkit поставляется с читаемыми исходными файлами. Сборка не использует минификацию, транспиляцию или объединение JavaScript. В исходный архив для проверки включайте `src/`, `manifests/`, `scripts/`, `tests/`, `package.json`, лицензию и документацию. Каталоги `dist/` и `release/` генерируются и не являются исходниками.

## 1. Подготовить окружение

| Компонент | Требование |
| :--- | :--- |
| **Node.js** | Ветка 22.x (воспроизводимая среда проекта: 22.16.0). |
| **npm** | Поставляется с Node.js; пример проверенной среды — 10.9.2. |
| **ОС** | Windows, macOS или Linux. |
| **Сторонние npm-пакеты** | Для сборки не требуются; `npm install` выполнять не нужно. |
| **Сеть** | Для локальной упаковки не требуется. Загрузка инструментов и подача в магазин выполняются отдельно. |

Загрузите Node.js с [официального сайта](https://nodejs.org/en/download) и проверьте версии:

```bash
node --version
npm --version
```

## 2. Собрать пакет, соответствующий исходникам

1. Распакуйте **полный исходный архив**. В его корне должны находиться `package.json`, `README.md`, `src/`, `manifests/`, `scripts/`, `tests/`, `LICENSE`.
2. Откройте терминал в корне.
3. Выполните:

```bash
npm run build-for-amo
```

Готовые файлы:

- `release/MajesticToolkit-2.4.0-firefox.zip` — Firefox для компьютера;
- `release/MajesticToolkit-2.4.0-firefox-android.zip` — Firefox для Android;
- `release/SHA256SUMS` — контрольные суммы;
- `release/release-manifest.json` — состав артефактов.

Для полного тестирования исходников и всех браузерных вариантов дополнительно выполните:

```bash
npm run verify
```

## 3. Что происходит при сборке

- `scripts/build.mjs` копирует исходный JavaScript, стили и ресурсы, формируя платформенные каталоги без генерации нового исполняемого кода.
- Браузерные манифесты читаются из `manifests/`; для Android и Safari формируются предусмотренные платформенные отличия.
- `scripts/package.mjs` создаёт воспроизводимые ZIP с фиксированным порядком файлов и временем записи.
- `scripts/verify.mjs` и `scripts/check-release.mjs` проверяют манифесты, права, синтаксис, имена, контрольные суммы и совпадение архивов с `dist/`.

Исходники должны соответствовать **именно отправляемому ZIP**. После любого изменения кода пересоберите пакет и приложите к проверке обновлённый исходный архив.

## 4. Сверить контрольную сумму

**Linux:**

```bash
sha256sum release/MajesticToolkit-2.4.0-firefox.zip
```

**macOS:**

```bash
shasum -a 256 release/MajesticToolkit-2.4.0-firefox.zip
```

**Windows PowerShell:**

```powershell
Get-FileHash -Algorithm SHA256 .\release\MajesticToolkit-2.4.0-firefox.zip
```

Сравните вывод с записью для нужного архива в `release/SHA256SUMS`. Если отправленный в AMO архив отличается от локального, проверьте, не пересобирался ли он из другого коммита.

## 5. Что не подтверждает успешная сборка

Сборка не означает подпись Mozilla, прохождение проверки магазина, работу Google OAuth на настоящем аккаунте или совместимость с живыми RP-форумами и физическим устройством Android. Эти шаги выполняются отдельно перед распространением.
