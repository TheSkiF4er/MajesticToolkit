# MajesticToolkit 1.7.1 — Менеджер жалоб 2.0
> **Архив релиза.** Здесь сохранены возможности, проверки и ограничения, актуальные на момент выпуска 1.7.1. Полная последовательность изменений — в [истории версий](../CHANGELOG.md).


- Очереди, приоритеты, теги, категории и ответственные.
- Поиск по игрокам и правилам, сортировка, сохранённые фильтры, страницы по 25 дел.
- Пакетное изменение метаданных, отслеживания и архивирование; завершение только после проверки всех дел.
- Ожидание, передача, повторная проверка и восстановление.
- Сохранение в Backup v15; штатные форумные действия не автоматизируются.
