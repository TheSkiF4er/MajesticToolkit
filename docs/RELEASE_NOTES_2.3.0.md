# MajesticToolkit 2.3.0 — Tactical Toolkit GA

**База:** 2.2.9. **Цель:** production-hardening тактической подсистемы и проверка выпускной готовности без изменения формата Backup v21.

## Изменения рабочего кода

- **Согласованность записи:** карта (изображение, слои, привязки, viewport), журналы аирдропов, планы, симуляции, источники и полное тактическое восстановление используют общий механизм сериализации. В поддерживающих браузерах `navigator.locks` координирует одновременно открытые вкладки. При отсутствии Web Locks работает последовательная очередь внутри текущего контекста.
- **Защита карты:** замена и удаление блокируются, если планы (включая архив), сохранённые симуляции или привязанные к карте точки аирдропов ссылаются на прежний SHA-256. Одинаковая подложка может быть загружена повторно, не стирая аннотации и калибровку. Если прежнее изображение утрачено, оригинал с тем же SHA-256 можно загрузить для восстановления работоспособности зависимых записей.
- **Безопасное удаление зависимостей:** архивный план удаляется только при отсутствии дочерних вариантов, связанных симуляций и источников. Аирдроп удаляется только после завершения/отмены и удаления связей с источниками. Архивная точка удаляется только без дочерних событий. Все необратимые действия подтверждаются в интерфейсе.
- **Rollback Backup v21:** перед заменой теперь фиксируются все карты IndexedDB, а не только карты профилей, имеющихся в импортируемом архиве. При отказе записи откат восстанавливает старые изображения всех профилей.
- **Replay:** обработка нескольких каптов в один день следует порядку записей реестра; каждый шаг воспроизведения меняет собственника ровно в момент соответствующего события, без преждевременного применения последующих каптов.

## Проверки и приёмка

- `npm test` — все Node.js тесты, включая `tests/tactical-ga-230.test.mjs` и `tests/tactical-ga-deletion-230.test.mjs`.
- `npm run verify` — тесты, сборки Chromium, Firefox, Firefox Android и Safari, синтаксическая проверка, упаковка и проверка SHA-256 готовых архивов.
- Chromium DOM-сценарии: `npm run test:browser:tactical-backup`, `npm run test:browser:tactical-analytics`, `npm run test:browser:map`, `npm run test:browser:planning`, `npm run test:browser:airdrops`, `npm run test:browser:simulation` (при наличии Playwright и Chromium).
- `npm run test:browser:tactical-ga` — отдельная проверка реального IndexedDB с оригинальным PNG, защитой архива, удалением зависимостей и изоляцией RP-профилей (требуется доступ к локальному HTTP-серверу браузера).

## Ограничения GA

Нет подключения к игровому клиенту и автоматического чтения телеметрии. Данные по каптам, аирдропам и симуляциям остаются локальными RP-записями. Backup v21 не является серверной транзакцией между независимыми хранилищами; при отказах используется предусмотренный откат, но внезапное аварийное завершение браузера посреди восстановления требует ручной проверки данных и повторной установки резервной копии. Проводите предрелизные ручные проверки расширения в реальном Firefox/Chromium и на Firefox Android/Safari. Автотесты на фикстурах не означают сертификацию площадок или магазинов расширений.
