# MajesticToolkit 2.1.1 — Economy & Crime Workspace

## Рабочие сценарии

Откройте `#economy`. Вкладка «Обзор» показывает настоящие операции активного профиля: чистый результат по завершённым сделкам и движениям денег, отдельно вложенный капитал в открытые сделки, график по дням, статистику игроков. Создавайте сделку, денежную операцию и результат игрока из быстрых действий, затем используйте редактор с обязательной проверкой полей. Данные сохраняются в исходном Economy Store (`rpnEconomyV4:`).

Вкладка «Рынок и сделки» показывает покупки и продажи; «Финансы» — денежные операции; «Семьи и игроки» — существующую группировку матчей по имени игрока и указанному полю «Семья». Выбор семьи открывает фильтр матчей этой группы. «Калькуляторы» содержат действующие расчёты перекупа, крафта и рейсов. «Журнал» позволяет фильтровать записи по типу, искать и экспортировать CSV. Обзор имеет отдельный поиск по названию, семье, игроку, категории, дате, примечанию и сумме; найденную запись можно открыть и редактировать.

## Данные и совместимость

Вкладка, поиск журнала, фильтр типа и история открытых записей сохраняются в `mtEconomyWorkspaceV211` отдельно по профилям. История не содержит копий записей; удалённые записи в ней автоматически игнорируются. При удалении профиля его предпочтения удаляются. Финансовые записи и формат Backup v19 не менялись; старые данные 2.1.0 читаются без миграции. Настройки интерфейса локальны и не включены в резервную копию финансового журнала.

## Ограничения

Организации 2.1.5, отдельный семейный реестр 2.1.4, каталог рыночных цен 2.1.2 и склад 2.1.3 ещё не реализованы. Поле «Семья» в сохранённых матчах служит только для реальной статистической группировки. Отсутствуют автоматическое получение цен с внешних серверов, серверная авторизация организаций и многопользовательская синхронизация.

## Проверка

`npm run verify`, `npm run test:browser:economy`. E2E проверяет создание/редактирование сделок, доходов, матчей, реальный поиск, фильтры, группировку семей, историю, сохранение настроек и изоляцию профилей. Для фактического production GA необходима проверка установленных расширений в целевых браузерах.
