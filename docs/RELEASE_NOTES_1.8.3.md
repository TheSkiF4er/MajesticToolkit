# MajesticToolkit 1.8.3 — Центр знаний 2.0
> **Архив релиза.** Здесь сохранены возможности, проверки и ограничения, актуальные на момент выпуска 1.8.3. Полная последовательность изменений — в [истории версий](../CHANGELOG.md).


Версия 1.8.3 реализует расширенную локальную библиотеку импортированных статей, коллекции знаний, историю редакций источников и поиск.

## Использование

1. Откройте **Рабочее пространство → Центр знаний**. Для импорта сначала откройте нужную тему форума или статью Fletcher Wiki в браузере, затем нажмите кнопку ручного импорта. Запрашиваются только прежние разрешения к соответствующему сайту.
2. Повторите импорт изменённой страницы: если текст или заголовок отличается, прежний текст будет сохранён как отдельная редакция, со временем захвата и SHA-256. Повторная загрузка идентичного материала не создаёт новую редакцию.
3. В разделе **Библиотека и редакции** используйте поиск по содержимому, тегам, статусу, типу, избранному или коллекции. Нажмите **Читать / редакции**, чтобы увидеть полный текст, обновить заметки, теги или отметить ручную проверку.
4. В истории нажмите **Сравнить** для отображения добавленных/удалённых слов. **Восстановить** возвращает выбранный текст как текущий, а прежний текущий текст остаётся в истории. Перед восстановлением проверяется SHA-256 выбранной редакции; статус проверки сбрасывается.
5. Создайте коллекцию и добавляйте в неё существующие статьи и другие связанные записи Центра знаний. Удаление коллекции не удаляет исходные записи.

## Совместимость и безопасность

- Действующий `SOURCE_KEY` и `KNOWLEDGE_KEY` сохранены; старые записи без редакций/коллекций автоматически читаются с пустой историей и пустыми коллекциями.
- Ссылки графа знаний сохраняются при повторном импорте и восстановлении статьи, поскольку ID статьи не меняется.
- Данные входят в прежний Backup v16 и его точку восстановления. Дополнительный блок или несовместимый формат копии не требуется.
- До 120 импортированных статей, до 8 предыдущих редакций на статью, до 60 коллекций, до 200 ссылок в коллекции. Каждая редакция ограничена 16 000 символами текста.
- Источники ограничены прежними официальными доменами RP-форумов и Fletcher Wiki, только HTTPS. Docossum остаётся ссылкой без автоматического импорта. Содержимое источников экранируется при выводе.
- Пометка **Проверено мной** означает только ручную проверку пользователем; автоматической проверки официальности или применимости правил нет.
- Инструменты не выполняют автоматическую модерацию и не публикуют решения.
- Chromium E2E использует автономные фикстуры браузера, не реальные авторизованные сайты; Safari и Firefox Android требуют отдельного тестирования на устройствах.

## Проверка

`npm run verify` и `npm run test:browser`. Архив изменённых файлов предназначен для применения поверх полного исходного дерева 1.8.2.
