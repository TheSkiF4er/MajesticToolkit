# MajesticToolkit 2.2.4 — Airdrop Operations

## Рабочая функциональность

В `#tactical` → **Аирдропы** доступны точки появления и самостоятельные RP-события:

- **Точки:** создание по клику на подложку карты или ручным вводом нормализованных X/Y (0–1); название, описание, архивирование и восстановление. Привязка к SHA-256 изображения: после замены подложки старые точки предупреждают об изменении карты и не показываются поверх нового изображения.
- **События:** планирование с точкой, локальной датой/временем, длительностью и описанием. Редактирование до запуска; запуск, получение с именем получателя и наградой, завершение или мотивированная отмена. Недопустимые переходы отклоняются.
- **Участники:** регистрация и исключение до завершения, проверка дублей, сохранение изменений в истории.
- **Таймеры:** живой обратный отсчёт при открытой вкладке для запланированных и активных событий, состояние просрочки. Расписание вводится пользователем, без утверждений о реальном серверном времени.
- **История:** все действия сохраняются как последовательность проверяемых событий, отдельная запись на профиль. Присутствуют статусы, поиск, фильтры, актуальные счётчики на Tactical Dashboard.
- **Перенос:** CSV (с защитой от формул в таблицах) и отдельный JSON экспорт/подтверждаемый импорт реестра с полной проверкой и откатом при ошибке; другие RP-профили не затрагиваются. При удалении профиля его точки и события очищаются.

Подложка игры по-прежнему загружается пользователем, а фактические игровые аирдропы автоматически не обнаруживаются. Аирдропы и бинарная карта пока **не входят в глобальный Backup v20** — для переноса аирдропов используйте JSON-экспорт вкладки; включение в переносимый Backup v21 запланировано для 2.2.9.

## Проверка

- `npm run verify` — все Node.js-тесты, синтаксис исходников и четырёх браузерных сборок, воспроизводимые пакеты и SHA-256.
- `npm run test:browser:airdrops` — полноценный Chromium E2E: загрузка подложки, клик для создания точки, аирдроп, участник, смена состояний, получение награды, история, фильтры, экспорт/импорт и изоляция профилей.
- `npm run test:browser:map-layers` и `npm run test:browser:tactical` — регрессии карты и Tactical Workspace.

Браузерный E2E использует реальный Canvas и изображения; IndexedDB предоставляется тестовым адаптером из-за ограничений раннера. Установка расширения во всех браузерах и серверная синхронизация не проверялись.

## Установка

Примените патч поверх полной версии **2.2.3** с сохранением структуры каталогов. Запустите `npm run verify` и `npm run test:browser:airdrops`. Патч содержит только изменённые исходники, тесты и конфигурации, без каталогов `dist` и `release`.
