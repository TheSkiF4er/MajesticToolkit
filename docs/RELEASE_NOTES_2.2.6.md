# MajesticToolkit 2.2.6 — Tactical Planning

Реализованы реальные операции в Tactical Toolkit → «Планирование»: создание плана на загруженной карте, выбор семьи/организации, управление тактическими группами, командирами и участниками, добавление точек кликом по Canvas, назначение групп на точки и построение упорядоченных маршрутов.

В планах хранятся действующие параметры, история изменений, альтернативные варианты и версии; доступны изменение маршрутов, архивирование и экспорт JSON и текстового отчёта. В отличие от фактических каптов симуляционных изменений территорий нет. Время маршрута вычисляется из длины в пикселях и пользовательской условной скорости; это не игровая навигация.

Точки привязаны к SHA-256 подложки карты, при замене карты активные планы защищены, профили изолированы, отсутствующие семьи/организации запрещены. Новый формат `mtTacticalPlanV226:*` хранится локально через `storage.local`; перенос этих планов в общем Backup v20 пока отсутствует (планируется Backup v21), экспорт JSON доступен из вкладки.

Проверки: `npm run verify`, `npm run test:browser:planning`. Браузерный E2E использует локальный тестовый IndexedDB-адаптер для карт.
