# Установка MajesticToolkit из ZIP: Chromium и Safari

Инструкция для **MajesticToolkit 1.5.3** и более ранних опубликованных ZIP-файлов. **Вместе с архивом не нужно устанавливать Node.js**, если вы распаковываете расширение вручную. Node.js 22 нужен только для сборки проекта и необязательного скрипта подготовки.

> **Важно:** скачанный ZIP не равен установщику. Chromium на ПК принимает *распакованную папку* с `manifest.json`; Safari на macOS умеет временно подключить ZIP или папку, но для постоянной установки и распространения нужен Safari Web Extension в приложении-контейнере (или упаковка через App Store Connect). На iPhone нельзя установить этот ZIP напрямую.

## 1. Скачать файлы

Откройте [GitHub Releases](https://github.com/TheSkiF4er/MajesticToolkit/releases) и выберите нужную опубликованную версию. Обычные файлы называются:

- **Chromium:** `MajesticToolkit-<версия>-chromium.zip`.
- **Safari:** `MajesticToolkit-<версия>-safari.zip`.
- **Контрольные суммы:** `SHA256SUMS` из того же выпуска.

Для **уже опубликованной 1.5.0** доступны прямые ссылки:

- [MajesticToolkit-1.5.0-chromium.zip](https://github.com/TheSkiF4er/MajesticToolkit/releases/download/v1.5.0/MajesticToolkit-1.5.0-chromium.zip)
- [MajesticToolkit-1.5.0-safari.zip](https://github.com/TheSkiF4er/MajesticToolkit/releases/download/v1.5.0/MajesticToolkit-1.5.0-safari.zip)
- [SHA256SUMS 1.5.0](https://github.com/TheSkiF4er/MajesticToolkit/releases/download/v1.5.0/SHA256SUMS)

**Это ссылки на 1.5.0, а не на 1.5.3.** Для 1.5.3 понадобятся пакеты из её отдельного опубликованного Release. Не переименовывайте ZIP старой версии, чтобы выдать его за новую.

Проверка SHA-256 при наличии утилиты:

```sh
# Linux / macOS: поместите SHA256SUMS и ZIP рядом
sha256sum -c SHA256SUMS        # Linux (для всех четырёх ZIP, если они скачаны)
shasum -a 256 MajesticToolkit-1.5.0-chromium.zip  # macOS; сравните со строкой SHA256SUMS
```

На Windows: `Get-FileHash -Algorithm SHA256 .\MajesticToolkit-1.5.0-chromium.zip`. Сравните значение со строкой `SHA256SUMS` для этого архива. Если скачали не все четыре ZIP, проверяйте хеш только нужного файла — общая команда может сообщить, что остальные файлы не найдены.

## 2. Chromium: Chrome / Edge / Brave / Opera / Vivaldi на компьютере

1. Скачайте `MajesticToolkit-<версия>-chromium.zip` на ПК с Windows, macOS или Linux.
2. Распакуйте **содержимое ZIP** в постоянную папку, например `Documents/MajesticToolkit`. Не устанавливайте расширение прямо из ZIP: Chrome принимает директорию, а не ZIP-файл.
3. Убедитесь, что **непосредственно в выбранной папке** находится `manifest.json`, рядом каталоги `ui/`, `background/` и `assets/`. Если `manifest.json` находится уровнем ниже, при выборе директории перейдите именно к нему.
4. Откройте страницу расширений в адресной строке: `chrome://extensions` (Chrome/Brave), `edge://extensions` (Edge) или страницу управления расширениями другого браузера на Chromium.
5. Включите **Режим разработчика / Developer mode**.
6. Нажмите **Загрузить распакованное расширение / Load unpacked** и выберите папку из пункта 2.
7. Убедитесь, что установлен **MajesticToolkit** с правильной версией. Закрепите значок через меню «Расширения» (значок пазла).
8. Откройте MajesticToolkit → **Профили** и **Сайты и доступ**. Создайте профиль Majestic RP или Russia Online и **по нажатию кнопки** выдайте разрешение только соответствующему форуму. Затем обновите открытую вкладку форума.

### Обновление без потери данных

Прежде чем менять установленную версию, сделайте экспорт резервной копии в MajesticToolkit. Для установки через `Load unpacked` держите папку на прежнем месте, замените файлы **внутри неё** содержимым нового Chromium ZIP и нажмите **«Обновить / Reload»** на странице расширений. Затем перезагрузите страницы форумов. Не удаляйте установленное расширение: удаление способно удалить его локальные данные и сменить ID при повторной установке.

При смене папки или идентификатора расширения локальные данные могут не перенестись автоматически. Установка из ZIP через Developer Mode предназначена для разработки и самостоятельного тестирования; штатная публичная установка для Chromium выполняется через магазин расширений.

### Диагностика Chromium

- **«Не удалось загрузить манифест»** — выбрана не та вложенная папка или ZIP распакован не полностью. Проверьте `manifest.json` в корне.
- **«Расширение отключено» / заблокировано политикой** — на управляемом устройстве администратор может запретить сторонние расширения. Не обходите политики устройства.
- **Нет кнопки на форуме** — проверьте доступ к домену в «Сайты и доступ», совпадение профиля с форумом и обновите вкладку.
- **После обновления интерфейс старый** — перезагрузите расширение на странице `chrome://extensions` и обновите страницу форума.
- **Потеряны настройки** — воспользуйтесь ранее экспортированной копией в разделе «Резервные копии».

## 3. Safari на macOS — временная установка без Xcode

Apple разрешает **временную установку Safari Web Extension** из папки или ZIP через инструменты разработчика (если эта функция имеется в установленной версии Safari). Это удобный путь для тестирования, а **не постоянная пользовательская установка**.

1. Скачайте `MajesticToolkit-<версия>-safari.zip`.
2. В Safari откройте **Safari → Настройки → Разработчик (Developer)**. Если вкладка разработчика скрыта, включите средства разработчика в настройках Safari.
3. Нажмите **Add Temporary Extension… / Добавить временное расширение…** и выберите исходный Safari ZIP или распакованную папку с `manifest.json`.
4. Подтвердите системное предупреждение о неподписанном расширении, если Safari его показывает.
5. Откройте **Safari → Настройки → Расширения**, включите MajesticToolkit и предоставьте разрешения на необходимые сайты.
6. Проверьте работу панели и откройте форумы Majestic RP и Russia Online в новой вкладке.

Safari удаляет временно подключённое расширение **после выхода из Safari или через 24 часа**. Такое расширение не является эквивалентом приложения из App Store. Если пункт `Add Temporary Extension` отсутствует, используйте способ с Xcode ниже.

## 4. Safari на macOS — приложение через Xcode

Для долгосрочного тестирования или распространения в Safari ресурсы ZIP необходимо упаковать в **macOS Safari Web Extension App**. Потребуются macOS и актуальный Xcode.

1. Распакуйте `MajesticToolkit-<версия>-safari.zip`, чтобы получить папку с `manifest.json`.
2. Откройте Terminal и перейдите в папку, содержащую распакованный архив.
3. Создайте Xcode-проект с помощью актуального средства Apple:

```sh
xcrun safari-web-extension-packager "/absolute/path/to/MajesticToolkit-safari" \
  --project-location "/absolute/path/to/MajesticToolkit-Safari-App" \
  --app-name "MajesticToolkit" \
  --swift \
  --copy-resources
```

Замените оба пути на реально существующие каталоги. **В актуальной документации Apple инструмент называется `safari-web-extension-packager`**; в старых версиях Xcode он назывался `safari-web-extension-converter`. При ошибке проверьте `xcrun safari-web-extension-packager --help` или `xcrun safari-web-extension-converter --help`.

4. Откройте созданный проект в Xcode, проверьте сообщения о неподдерживаемых ключах `manifest.json` и совместимость Safari API. При необходимости скорректируйте Xcode-проект и нативную конфигурацию; оригинальный архив Chromium здесь не подходит.
5. В **Signing & Capabilities** выберите собственную Apple Team и уникальный Bundle Identifier для приложения. Для App Store потребуется действующая регистрация разработчика и подпись. Значение Bundle Identifier нельзя безопасно универсализировать для всех пользователей.
6. Выберите схему macOS-приложения → **Product → Run**. Запустите приложение-контейнер, откройте Safari → Настройки → Расширения и включите MajesticToolkit.
7. Проверяйте работу функций Safari непосредственно в Safari на macOS. Наличие успешно созданного Xcode-проекта само по себе не подтверждает полную совместимость его WebExtension API.

**iPhone/iPad:** нельзя открыть Safari ZIP и установить расширение как браузерное дополнение. Требуется iOS/iPadOS-приложение-контейнер, собранное средствами Apple и установленное через соответствующий механизм (Xcode/TestFlight/App Store). Для упаковки без Mac Apple также предоставляет интерфейс Safari Web Extension Packager в App Store Connect; публикация всё равно требует проверки и подписи.

### Обновление Safari

- **Временное расширение:** снова добавьте ZIP через Developer; хранение настроек после удаления временного дополнения не гарантируется — предварительно экспортируйте данные.
- **Приложение через Xcode:** обновите ресурсы проекта из новой Safari-сборки, увеличьте версию нативного приложения, соберите и запустите его с теми же Team и Bundle Identifier. Не удаляйте приложение до экспорта резервной копии.

## 5. Необязательная подготовка ZIP через Node.js 22

Если вы работаете с **полным исходным репозиторием**, скрипт подготовки безопасно распаковывает пакеты Chromium и Safari в отдельный каталог и проверяет содержимое, версию, CRC32, а также SHA-256 при наличии `SHA256SUMS` рядом с ZIP. Он **не устанавливает** расширение в браузер и не требует npm-зависимостей.

```sh
npm run verify
npm run prepare:chromium
npm run prepare:safari
```

Для уже скачанного ZIP укажите явный путь:

```sh
node scripts/prepare-install.mjs chromium "/path/to/MajesticToolkit-1.5.3-chromium.zip" "/path/to/unpacked-chromium"
node scripts/prepare-install.mjs safari "/path/to/MajesticToolkit-1.5.3-safari.zip" "/path/to/unpacked-safari"
```

Скрипт не перезаписывает существующую папку установки. Он принимает только версию, соответствующую `package.json` исходного проекта. Для ZIP 1.5.0 используйте **исходники и инструмент версии 1.5.0** либо ручное распаковывание — не подменяйте номер версии в пакете.
