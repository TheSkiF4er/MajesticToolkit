# Установка MajesticToolkit в Chromium и Safari

**Версия 2.4.0** · [Скачать пакеты](https://github.com/TheSkiF4er/MajesticToolkit/releases/tag/v2.4.0) · [Инструкции для Firefox](AMO_SUBMISSION.md)

> **Перед началом.** ZIP из GitHub Releases — это архив ресурсов расширения, а не универсальный установщик. В Chromium для самостоятельной установки требуется распакованная папка. В Safari для постоянной установки требуется приложение-контейнер, созданное и подписанное средствами Apple. На iPhone/iPad прямой установки Safari ZIP нет.

## 1. Скачать и проверить пакет

В [выпуске 2.4.0](https://github.com/TheSkiF4er/MajesticToolkit/releases/tag/v2.4.0) доступны:

| Файл | Для чего нужен |
| :--- | :--- |
| `MajesticToolkit-2.4.0-chromium.zip` | Chrome, Edge, Brave и другие Chromium-браузеры на компьютере. |
| `MajesticToolkit-2.4.0-firefox.zip` | Firefox для компьютера; постоянная установка требует подписи. |
| `MajesticToolkit-2.4.0-firefox-android.zip` | Отдельная сборка для Firefox Android. |
| `MajesticToolkit-2.4.0-safari.zip` | Ресурсы Safari Web Extension для тестовой загрузки или упаковки в приложение. |
| `SHA256SUMS` | Контроль целостности файлов выпуска. |

Проверьте сумму скачанного архива; имена в командах ниже соответствуют **версии 2.4.0**.

**Linux:**

```bash
sha256sum MajesticToolkit-2.4.0-chromium.zip
```

**macOS:**

```bash
shasum -a 256 MajesticToolkit-2.4.0-safari.zip
```

**Windows PowerShell:**

```powershell
Get-FileHash -Algorithm SHA256 .\MajesticToolkit-2.4.0-chromium.zip
```

Сравните полученный SHA-256 со строкой соответствующего файла в `SHA256SUMS` **из того же выпуска**. Полная команда `sha256sum -c SHA256SUMS` подходит, если все упомянутые в нём ZIP находятся рядом. Не переименовывайте архив старой версии в новый.

## 2. Chromium на Windows, macOS и Linux

1. Скачайте `MajesticToolkit-2.4.0-chromium.zip`.
2. Распакуйте **содержимое** архива в постоянную папку, например `Документы/MajesticToolkit`. Убедитесь, что непосредственно в этой папке находится `manifest.json`.
3. Откройте страницу расширений браузера: `chrome://extensions` для Chrome/Brave или `edge://extensions` для Edge.
4. Включите **«Режим разработчика»** и нажмите **«Загрузить распакованное расширение»**.
5. Выберите папку из пункта 2. В карточке расширения должна отображаться версия 2.4.0.
6. Закрепите значок, откройте расширение и создайте профиль Majestic RP или Russia Online.
7. В разделе **«Сайты и доступ»** разрешите нужный форум, затем обновите его вкладку. Разрешения для других сервисов можно не выдавать.

### Обновление без потери данных

До обновления экспортируйте резервную копию. Если расширение установлено из распакованной папки, **не меняйте её путь и идентификатор расширения**: замените содержимое папки новым пакетом и нажмите **«Обновить»** на странице расширений. После этого обновите вкладки форумов.

Удаление дополнения или установка под другим ID может привести к потере локального хранилища. Для постоянного массового распространения Chromium требуется соответствующий магазин расширений и его проверка.

### Частые ошибки

| Симптом | Что проверить |
| :--- | :--- |
| «Не удалось загрузить манифест» | Выбрана вложенная папка или ZIP не распакован. Ищите `manifest.json` в корне выбранного каталога. |
| На форуме нет панели | Разрешение для домена, соответствие RP-профиля открытому форуму, обновление вкладки. |
| После обновления старый интерфейс | Обновите дополнение на странице расширений и перезагрузите форум. |
| Расширение запрещено политикой | На управляемом устройстве установка может быть ограничена администратором; эти ограничения не следует обходить. |
| Отсутствуют прежние данные | Проверьте идентификатор дополнения и восстановите собственную резервную копию. |

## 3. Safari на macOS · временное подключение

На поддерживаемых версиях Safari инструменты разработчика позволяют временно подключить ресурсы Web Extension для испытаний. Доступность пункта зависит от версии браузера.

1. Скачайте `MajesticToolkit-2.4.0-safari.zip`.
2. Откройте настройки Safari и включите средства разработчика, если соответствующее меню скрыто.
3. В меню разработчика выберите **«Добавить временное расширение»** (если пункт доступен) и укажите ZIP или распакованную папку с `manifest.json`.
4. Подтвердите запросы Safari и включите MajesticToolkit в **«Настройки → Расширения»**.
5. Выдайте необходимые разрешения и проверьте работу на своих RP-форумах.

Временный вариант не равнозначен подписанной постоянной установке: он может отключаться или удаляться браузером. Перед его удалением экспортируйте локальные данные.

## 4. Safari на macOS · упаковка через Xcode

Для полноценного распространения понадобятся macOS, Xcode и при необходимости действующая учётная запись разработчика Apple.

1. Распакуйте Safari ZIP в каталог с `manifest.json`.
2. С помощью штатного средства Apple создайте проект приложения-контейнера. Ниже приведён **пример**; замените пути на существующие на вашей машине:

```bash
xcrun safari-web-extension-packager "/absolute/path/to/MajesticToolkit-safari" \
  --project-location "/absolute/path/to/MajesticToolkit-Safari-App" \
  --app-name "MajesticToolkit" \
  --swift \
  --copy-resources
```

3. Откройте проект в Xcode и проверьте сообщения о ключах манифеста, поддержке API и целевых версиях Safari.
4. Укажите собственные параметры **подписи и идентификатора приложения**. Для распространения в App Store требуется выполнение условий Apple.
5. Соберите и запустите контейнер, включите расширение в настройках Safari и проверьте работу на устройстве.

**iPhone и iPad:** ZIP нельзя установить напрямую. Понадобятся соответствующее приложение-контейнер для iOS/iPadOS, подпись и отдельная проверка совместимости. Успешная сборка на macOS не подтверждает поддержку iOS.

### Обновление Safari

Для временного расширения импортируйте актуальные ресурсы повторно после сохранения резервной копии. Для приложения Xcode обновите ресурсы, номер версии приложения и выполните повторную сборку и подпись; проверьте сохранение идентификатора расширения и локальных записей.

## 5. Подготовка папок из полного исходного проекта

Если у вас есть **полный репозиторий** с Node.js 22, можно собрать и подготовить каталоги командами:

```bash
npm run verify
npm run prepare:chromium
npm run prepare:safari
```

Для собственного пути к готовому ZIP:

```bash
node scripts/prepare-install.mjs chromium "/path/to/MajesticToolkit-2.4.0-chromium.zip" "/path/to/unpacked-chromium"
node scripts/prepare-install.mjs safari "/path/to/MajesticToolkit-2.4.0-safari.zip" "/path/to/unpacked-safari"
```

Скрипт проверяет пакет и отказывается перезаписывать существующий целевой каталог. Версия архива должна соответствовать метаданным исходников; подготовка не устанавливает дополнение в браузер автоматически.
