# MajesticToolkit 2.2.2 — Interactive World Map

## Рабочая функциональность

- `#tactical` → **Карта**: интерактивная локальная карта с загрузкой реального файла PNG, JPEG или WebP из файлов пользователя (не удалённые URL/не фиктивная подложка).
- **Canvas**: панорамирование перетаскиванием, масштабирование колёсиком, кнопками и щипком на сенсорном экране; клавиатура: стрелки, `+`, `−`; вписать изображение; полноэкранный режим.
- **Координаты**: отображение точных пикселей изображения под указателем. Трёхточечная аффинная калибровка переводит их в игровые X/Y, включая поворот или перекос изображения. Невырожденность точек проверяется при сохранении.
- **Постоянное хранение**: изображение как бинарный Blob и метаданные в браузерном IndexedDB, отдельно от лимитов `chrome.storage.local`; масштаб, центр и опорные точки сохраняются по профилям. Замена или удаление карты доступны пользователю.
- **Безопасность и надёжность**: PNG/JPEG/WebP без SVG/HTML; проверка сигнатуры файла, размера (25 МиБ), разрешения (16384 px по стороне, 64 млн пикселей), SHA-256 при открытии, проверка профиля, отклонение повреждённых записей и возможность удаления повреждённой подложки.
- **Реальная интеграция**: карта — вкладка существующего Tactical Workspace, остальные вкладки работают с настоящими реестрами Crime & Territory, Families, Organizations. Переход между разделами не удаляет локальную карту.
- **Удаление RP-профиля** очищает и его картографический Blob. Ошибки очистки логируются, а не скрываются.

## Ограничения и совместимость

Официальное изображение Majestic RP и точные игровые координаты отсутствуют в проекте: пользователь выбирает свою подложку и сам калибрует координаты по трём известным точкам. Автоматическое определение игрового положения, аирдропы, маркеры и полигоны относятся к следующим релизам. **Backup v20 не содержит локальные картографические Blob**; перенос с включением изображений запланирован на Backup v21 / 2.2.9. Текущие Economy & Crime, Government & Justice и Backup v20 не изменяются.

## Проверки

- `npm run verify` — полный Node.js-набор, четыре платформенные сборки и проверка SHA-256.
- `npm run test:browser:tactical` — регрессия действующих записей территорий и событий.
- `npm run test:browser:map` — Chromium: загрузка и декодирование реального изображения, Canvas-масштаб, сохранение, калибровка трёх точек, профильная изоляция, блокировка изменённого SHA-256. Тестовый раннер блокирует переход на HTTP-адрес, поэтому IndexedDB в этом **браузерном E2E** заменён детерминированным адаптером, при сохранении фактического рендеринга изображения и выполнения UI-кода в Chromium; установленная в расширении нативная IndexedDB этим прогоном не проверена.

## Установка

Распакуйте архив изменений поверх полного проекта 2.2.1 с сохранением путей и выполните `npm run verify`.
