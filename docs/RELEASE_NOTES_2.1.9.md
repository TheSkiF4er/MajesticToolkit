# MajesticToolkit 2.1.9 — Economy Integrations & Data Migration

## Рабочие функции

- Economy & Crime → **«Импорт и связи»**: новая рабочая вкладка для обмена рыночными данными и привязки реальных документов/материалов Evidence Vault.
- **Импорт Marketplace CSV и JSON**: загрузка файла до 2 МиБ и 5000 строк, разбор экранированных полей, проверка названий и ссылок товаров, предпросмотр количества новых/пропущенных записей **без записи в хранилище**, отдельное подтверждение изменений.
- **Защита от дублей**: сравнение товаров по нормализованным названию, категории и варианту; ценовых наблюдений и объявлений — по реквизитам, датам, источникам и стоимости. Ссылки импорта связываются с товаром текущего RP-профиля; недействительные записи отклоняются с номером строки.
- **Защита от конкурентной записи**: проверка состояния каталога производится повторно непосредственно внутри блокировки записи; импорт добавляет новые записи, не перезаписывая чужие изменения. В случае сбоя хранилища выполняется откат.
- **Экспорт рынка**: продукты, наблюдения цен и объявления выбранного RP-профиля в CSV и JSON, с сохранением кириллицы, кавычек, переносов строк и защитой от формул в CSV.
- **Сквозные связи** по стабильным ID для товаров, семей, организаций, территорий с документами Document Studio и локальными материалами Evidence Vault. Без копирования двоичных вложений; проверка профиля, источника и целевого объекта перед созданием, удалением и восстановлением. Удаление связанной записи без предварительной отвязки запрещено.
- **Backup v20**: сохранение проверенных экономических связей вместе со всеми прежними разделами, судопроизводством, каталогом рынка, складом, семьями, организациями, территориями, финансами и документами. Ссылки проверяются до выдачи файла и до восстановления. Переносимый ZIP по-прежнему включает реальные файлы Evidence Vault с SHA-256; JSON — только метаданные вложений.
- **Исторические Backup v1–v19** по-прежнему импортируются: отсутствующее поле новых экономических связей не удаляет ранее сохранённые локальные связи, но перед восстановлением выполняется проверка их дальнейшей применимости.
- Удаление RP-профиля удаляет и его экономические связи; операции восстановления сохраняют прежние данные при неудаче.

## Проверка и ограничения

Запустите `npm run verify` и `npm run test:browser:eco-integrations`. Сквозной тест охватывает привязку источника, блокировку его удаления, импорт CSV с предпросмотром, подтверждение, экспорт JSON, разделение профилей и резервное копирование.

Все функции работают с **локальными пользовательскими данными**. Импорт рынка не сканирует форумы автоматически и не синхронизирует данные с игровым сервером. В этом релизе нет автоматической интеграции финансовых транзакций и складских движений в единый бухгалтерский баланс — независимые источники не суммируются без проверки происхождения операций. Текущий импорт CSV/JSON ориентирован на каталог Marketplace; полное восстановление всех подсистем выполняется через Backup v20.

## Обновление

Наложите архив **только изменённых файлов 2.1.9** поверх **полного проекта 2.1.8**, соблюдая структуру каталогов. Затем выполните `npm run verify`. Старые записи мигрируют без необходимости повторного ввода.
