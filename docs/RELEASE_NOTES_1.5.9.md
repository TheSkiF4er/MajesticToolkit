# MajesticToolkit 1.5.9 — Оформление форума
> **Архив релиза.** Здесь сохранены возможности, проверки и ограничения, актуальные на момент выпуска 1.5.9. Полная последовательность изменений — в [истории версий](../CHANGELOG.md).


## Использование

В рабочем пространстве откройте «Форум» → «Оформление форума». Выберите область (общая, форум активного профиля или профиль), тему и параметры. Предпросмотр обновляется до применения. «Применить» записывает настройки в локальное хранилище; открытые вкладки с предоставленным доступом получают обновление. «Оригинал» загружает исходные значения в редактор, а «Сбросить область» возвращает наследование либо исходные настройки для глобальной области. «Отменить изменение» восстанавливает предыдущее сохранённое состояние области.

Семь тем: Original, Toolkit Dark, Toolkit Light, Midnight, OLED, System и Custom. Шесть цветов проверяются как HEX, шрифты из ограниченного списка, размер 12–22 и скругление 0–20. Для пользовательских цветов отображается предупреждение о низком контрасте. Пресеты Player, Moderator, Government, Court и Minimal меняют только визуальные параметры. До 30 собственных пресетов можно сохранить, загрузить и удалить. Экспорт/импорт JSON переносит одну тему, не выполняя CSS или JavaScript.

Настройки компоновки применяются к известным компонентам XenForo. Боковая панель перемещается только при подходящей структуре DOM и ширине не менее 1000 px; на мобильных устройствах сохраняется штатная компоновка. Minimal ограничивает высоту известных необязательных виджетов, не удаляя предупреждения, формы и CAPTCHA. При отключении расширения, отзыве доступа или возврате к оригиналу добавленные стили и элементы удаляются. Существующие формы, обработчики отправки и полномочия остаются штатными.

Внутри форума откройте MT → «Оформление и чтение». Режим чтения можно переключить локально, развернуть цитату или подпись и перейти к сообщению через список текущей страницы. Если в студии включено запоминание места, пользователь может явно сохранить позицию, вернуться к ней и очистить её. Запись хранится в закрытом хранилище расширения, до 50 тем на профиль; query/hash URL не сохраняются. Новых разрешений или сетевых запросов нет.

## Совместимость и проверка

Настройки и пресеты входят в существующий Backup v14; старые копии остаются валидны. Отметки чтения не экспортируются. Исходное оформление по умолчанию не меняется. `npm run verify` проверяет тесты и четыре релизных сборки; `npm run test:browser` запускает автономные браузерные фикстуры XenForo. Живые авторизованные форумы и устройства Safari/Firefox Android требуют отдельной проверки; тема сайта может иметь дополнительные нестандартные селекторы.
