# MajesticToolkit v1.5.0 — Production Readiness

Обновление **MajesticToolkit** — локального браузерного расширения для Majestic RP, Russia Online и RP-форумов на XenForo. Это первый публичный выпуск после 1.0.0, поэтому ниже перечислены изменения 1.1.0–1.5.0.

## Что нового

### 1.5.0 — безопасность, надёжность и браузерные тесты
- Усилена проверка источников сообщений, контекста фрейма и допустимого размера сообщений фонового процесса.
- Исправлена привязка жалоб и видеодоказательств к игровому профилю соответствующего форума.
- Перерегистрация контентных скриптов при обновлениях расширения; предотвращение лишних операций записи при мониторинге тем.
- Потоковое ограничение размера API-ответов Server Monitor.
- Автоматизированные E2E в реальном Chromium и Firefox на автономных HTML-фикстурах XenForo.
- Регрессионные проверки, детерминированные ZIP-пакеты и SHA-256 для всех сборок.

### 1.1.0–1.4.0 — новые возможности после 1.0.0
- **XenForo Integration:** надёжный BBCode-биндер для Froala/textarea, пользовательская навигация, публичные карточки форумных пользователей, запуск только штатных действий модерации.
- **Server Monitor & Player Profiles:** каталог Majestic RP / Russia Online, избранные серверы, запросы подтверждённого онлайна, сохранение открытых карточек пользователей. Непроверенные показатели не отображаются как фактические.
- **External Knowledge & Workspace:** Центр знаний, ссылки Fletcher Wiki и Docossum, двусторонние связи между документами, законами и шаблонами, работа с Google Docs/Sheets через разрешённый OAuth/Drive API.
- **Forum Workflow Automation:** этапы рассмотрения жалоб, контрольные списки, журнал действий, черновики решений и уведомления о сроках без автоматической отправки публикаций.

## Прикреплённые файлы
- `MajesticToolkit-1.5.0-chromium.zip` — Chrome, Edge, Brave и другие Chromium-браузеры.
- `MajesticToolkit-1.5.0-firefox.zip` — Firefox Desktop.
- `MajesticToolkit-1.5.0-firefox-android.zip` — Firefox Android (при поддерживаемой установке).
- `MajesticToolkit-1.5.0-safari.zip` — **только ресурсы** для создания Safari Web Extension; не готовый .app или .ipa.
- `SHA256SUMS` и `release-manifest.json` — проверка целостности сборок.

Исходный код доступен в автоматически формируемом GitHub архиве тега `v1.5.0`. Проверка SHA-256: распакуйте `SHA256SUMS` в каталог с ZIP и выполните `sha256sum -c SHA256SUMS`.

## Установка
- **Chromium:** распакуйте ZIP и выберите «Загрузить распакованное расширение» на `chrome://extensions` в режиме разработчика.
- **Firefox:** пакет должен быть подписан через Mozilla Add-ons для обычной постоянной установки; неподписанный ZIP можно загрузить временно для разработки через `about:debugging`.
- **Safari:** требуются средства Apple для упаковки и подписи приложения-контейнера.

При обновлении используйте прежний ID дополнения. Перед удалением старой установки экспортируйте резервную копию локальных данных.

## Проверки и ограничения
- GitHub Actions: `test-and-build` и `browser-e2e` — успешно для исходников перед релизом.
- Браузерные тесты проверяют DOM на **локальных фикстурах XenForo**, но не подтверждают работу установленного дополнения на живых страницах Majestic RP и Russia Online.
- Реальные сценарии Google OAuth, Firefox Android и Safari требуют отдельного приёмочного тестирования.
- Расширение не обходит права пользователей, не извлекает закрытые данные и не публикует решения или сообщения автоматически.
- Fletcher Wiki и Docossum используются для навигации и пользовательских ссылок; скрытый сбор их данных не выполняется.
