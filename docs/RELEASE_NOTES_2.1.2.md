# MajesticToolkit 2.1.2 — Marketplace & Price Intelligence

## Что работает

1. В `#economy` → **Рынок и сделки** нажмите **Добавить товар**. Укажите название, категорию, вариант, единицу измерения; сохранённый товар доступен после перезагрузки, его можно изменять и архивировать.
2. Выберите **Цены** для товара и **Добавить цену**. Укажите дату, тип (`Предложение продажи`, `Предложение покупки`, `Фактическая сделка`), цену за единицу, количество и обязательное название источника. HTTPS-ссылка необязательна. Цена сразу отображается в таблице и графике.
3. Выберите **Добавить объявление**. Укажите покупку/продажу, статус, цену, количество, контакт, дату и срок действия. Завершайте и отменяйте объявления через **Изменить**. Истёкшие по дате объявления не учитываются в актуальном спросе/предложении.
4. Просматривайте медиану (по завершённым сделкам, а при их отсутствии — по всем наблюдениям), диапазон, лучший bid/ask, изменение первого и последнего наблюдения. Данные не приходят с сервера и не являются официальными котировками.
5. Используйте поиск товаров, показ архивных записей, фильтрацию активным профилем и **Экспорт CSV**. CSV дополнительно экранирует значения, которые табличный редактор может интерпретировать как формулы.
6. В «Рынок и сделки» остался старый журнал покупок/продаж с прежним финансовым расчётом. Он не смешивает наблюдения рыночных цен с завершёнными финансовыми сделками, чтобы не завышать прибыль.

## Хранение и совместимость

- Рынок: записи `product`, `price`, `listing` под ключами `mtMarketplaceV212:`, локальный `browser.storage.local`. Все ссылки проверяются на наличие товара **в том же профиле**; удаление используемого товара запрещено, но доступно архивирование. Валидация дат, сумм и URL выполняется при каждом чтении и изменении.
- Экспорт Backup v19 дополнен необязательным полем `marketplace`. Импорт проверяет записи и ссылки до замены, при сбое восстанавливает предыдущие записи. Старый Backup v19 без поля `marketplace` **не удаляет** новый каталог; если такая копия удаляет профили, у которых есть рыночные записи, импорт запрещается. Поддержка резервных копий v1–v18 сохраняется.
- Импорт/экспорт не синхронизирует реальные объявления RP-серверов, не проверяет подлинность названного источника и не выполняет автоматические рыночные запросы.

## Проверка

`npm run verify` · `npm run test:browser:marketplace` · `npm run test:browser:economy`.

Для окончательной production-приёмки необходимы проверки установленного расширения в целевых браузерах и на реальных RP-сценариях. Отдельный складской учёт запланирован на 2.1.3.
