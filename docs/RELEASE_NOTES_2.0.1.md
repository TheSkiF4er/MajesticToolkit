# MajesticToolkit 2.0.1 — Рабочее пространство государства и правосудия
> **Архив релиза.** Здесь сохранены возможности, проверки и ограничения, актуальные на момент выпуска 2.0.1. Полная последовательность изменений — в [истории версий](../CHANGELOG.md).


**Обновление:** распакуйте ZIP с изменёнными файлами поверх исходного проекта **2.0.0** с сохранением относительных путей. Это не полное расширение и не новый формат данных. Затем выполните `npm test` и `npm run build`; установите результат из `dist/<browser>`.

## Реальный функционал

- Новый рабочий маршрут `#justice`, отдельный пункт в навигации, быстрый вход с главного экрана и из popup. Старые `#government`, `#law` и `#documents` доступны.
- Шесть вкладок: **Обзор**, **Суды**, **Ведомства**, **Законодательство**, **Решения**, **Документы**. Сводка рассчитывается по текущему профилю из реальных записей.
- Поиск по названиям, номерам, фактам решений, статьям действующих редакций законов, тексту документов и шаблонов. Переходы открывают действующие редакторы/просмотры.
- Судебная вкладка показывает только сохранённые судебные ведомства Government Tools, а не синтетические учреждения; добавление судов выполняется настоящей формой создания ведомства, сохранение и валидация не изменены.
- Рабочие кнопки создания/редактирования ведомства, закона, решения, документа и процессуального шаблона; документы работают через Document Studio, решения через Government Tools.
- Изоляция данных по профилю и сохранение последней выбранной вкладки и последних 30 открытых записей с проверкой ссылок при чтении. Для новых предпочтений используется ключ `mtGovernmentJusticeWorkspaceV201`; исходные записи не переносятся.

## Границы релиза

2.0.1 — **единый интерфейс**, не самостоятельная система судебного производства: реестр дел, процессуальные действия, заседания, новые полномочия и совместная синхронизация не заявлены. Санкции не назначаются автоматически. Экспорт Backup v18 и импорт v1–v18 остаются без изменения; интерфейсные предпочтения 2.0.1 можно настроить заново после переноса.

## Проверка

- `npm test` — Node.js, включая изоляцию профилей, реальные изменения в хранилищах и XSS-проверки.
- `npm run build` / `node scripts/verify.mjs` — четыре кросс-браузерные сборки.
- `python tests/browser-e2e.py` — реальные DOM-сценарии в Chromium на офлайн-фикстурах (нужен установленный Playwright).
