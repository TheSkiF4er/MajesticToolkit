# MajesticToolkit 2.2.9 — Tactical Integrations & Data Migration

**База:** 2.2.8. **Тема:** сквозные связи и Backup v21.

## Новые рабочие сценарии

### Сквозные ссылки

В `#tactical` откройте вкладку «Связи и источники». Выберите существующую территорию, аирдроп, план или симуляцию; выберите документ из Document Studio или материал Evidence Vault, добавьте комментарий и сохраните. Ссылка сохраняется в RP-профиле по ID, её можно удалить из этой вкладки. Связанный исходный документ/материал нельзя удалить без отвязки. Источники и тактические объекты должны принадлежать одному профилю.

### Полный перенос Backup v21

В системном разделе резервных копий выберите «Переносимая копия ZIP». Архив содержит системный Backup v21 (все прежние реестры, включая документы и доказательства), тактические журналы, слои и геометрию карты, историю привязок, бинарные изображения PNG/JPEG/WebP и вложения Evidence Vault. Манифест перечисляет файлы и их SHA-256. При восстановлении приложение проверяет целостность архива, профили, метаданные изображений и связи до изменения хранилищ. Несогласованная или повреждённая копия отклоняется; при ошибке записи выполняется восстановление предыдущих данных.

### JSON и старые версии

JSON Backup v21 включает метаданные карт, но **не включает байты изображения**. Для импорта JSON на другом устройстве уже должна существовать идентичная карта с тем же SHA-256; иначе импорт отклоняется и предлагается ZIP. Backup v1–v20 поддерживается. Формат, в котором отсутствует новая тактическая подсистема, сохраняет уже существующие на устройстве тактические записи при условии целостности ссылок и совпадения профилей.

## Проверки

- `npm run verify`: Node.js tests, сборки Chromium/Firefox/Firefox Android/Safari, проверка исходников и SHA-256 релизных ZIP.
- `npm run test:browser:tactical-backup`: сценарий Chromium с реальной загрузкой карты и операциями в локальном тестовом хранилище, регистрацией аирдропа, планом, симуляцией, связью с документом, ZIP-экспортом, очисткой и восстановлением.
- В браузерных сценариях картографическое IndexedDB заменено тестовым адаптером; установка расширения в реальные браузеры не проверялась.

## Ограничения

Нет автоматической синхронизации с сервером Majestic RP или игровой телеметрии. Для больших карт и файлов контролируйте доступное дисковое пространство. Перед восстановлением рекомендуется сохранять текущую переносимую копию ZIP.
