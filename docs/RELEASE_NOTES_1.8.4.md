# MajesticToolkit 1.8.4 — Evidence & Knowledge Graph

## Рабочие возможности

1. Откройте **Рабочее пространство → Центр знаний → Граф доказательств и знаний**. Для цитирования сначала импортируйте доступную тему форума или Fletcher Wiki вручную в «Библиотека и редакции». В карточке источника нажмите **Цитировать текущую редакцию** либо **Цитировать редакцию** для старой версии.
2. Выберите сохранённую редакцию и скопируйте дословный фрагмент не длиннее 1200 символов. При создании проверяется точное включение текста и контрольная сумма SHA-256 всей редакции. Сохраняются название, URL, дата редакции, границы фрагмента, контрольная сумма и пользовательская заметка. Снимок цитаты не изменяется при последующих обновлениях источника.
3. В форме связей выберите два существующих узла активного профиля и тип связи: подтверждает, оспаривает, цитирует, применимо к, использовано в или связано с. Можно связывать цитаты, жалобы, события таймлайна, доказательства, правила и зарегистрированные решения. Пользователь задаёт смысл связи; Toolkit не устанавливает виновность.
4. Выберите жалобу в фильтре графа, чтобы просмотреть связанные цепочки и выбрать относящиеся к делу доказательства или события. Из Complaint Manager воспользуйтесь кнопкой **Связи с источниками** для перехода к конкретному делу.
5. Ссылка на удалённую/недоступную историческую запись показывается как отсутствующая. Источник с сохранёнными цитатами нельзя удалить до удаления связей и цитат. Цитата с действующими связями также защищена от удаления.

## Хранение и безопасность

- Граф включён в существующее хранилище Knowledge Workspace и **Backup v16**; старые копии без графа восстанавливаются с пустым графом.
- Максимум 500 цитат, 1500 связей; общий блок графа ограничен 1,6 МБ. Профильная изоляция проверяется при создании и восстановлении.
- Связь с источником — локальная пользовательская интерпретация. SHA-256 фиксирует сохранённый текст, но не подтверждает официальность или подлинность страницы форума. Если источник меняется, историческая цитата не перезаписывается.
- Никаких новых браузерных разрешений, автоматического скачивания Docossum, публикаций или игровых санкций не добавлено. Локальные бинарные материалы Evidence Vault по-прежнему не входят в JSON Backup v16.

## Проверка

`npm run verify` и `npm run test:browser`; четыре платформенные сборки, синтаксис, манифесты, ZIP и SHA-256. Browser E2E на автономных XenForo-фикстурах, без приёмки на реальных авторизованных форумах. GitHub Release публикуется только через отдельный workflow после прохождения CI.
