# MajesticToolkit 2.2.7 — Tactical Simulation Engine

## Рабочие сценарии

1. В `Tactical Toolkit → Карта` загрузите изображение игрового мира.
2. В `Планирование` создайте план с минимум одним маршрутом из двух точек; укажите условную скорость в пикселях/мин. Можно создать несколько вариантов плана.
3. В `Симуляции` выберите план, задайте время старта, множитель скорости, задержку в промежуточных точках, радиус пересечения, разброс скорости, seed и число прогонов (до 80).
4. Выполните запуск. На Canvas отображаются маршруты и рассчитанные позиции; ползунок позволяет просматривать состояние в выбранную минуту. Внизу — таблица маршрутов, пересечения и распределение времени.
5. Выполните второй запуск с другими параметрами или из альтернативного плана и выберите его для сравнения. Экспортируйте отдельный результат JSON, временную шкалу CSV либо все запуски профиля JSON.

## Данные и надёжность

- Результаты сохраняются под ключами `mtTacticalSimulationV227:*` в локальном хранилище расширения. Записи содержат строгую копию исходного плана, контрольную сумму подложки, параметры модели и воспроизводимый результат. Результат перепроверяется повторным вычислением при каждом чтении. Данные других RP-профилей недоступны.
- Проверяются пределы настроек, количество маршрутов, длина маршрута, продолжительность симуляции и размер записи. Операции создания и удаления выполняются под сериализованной блокировкой.
- Карта, используемая сохранённой симуляцией, не может быть удалена или заменена, пока соответствующие запуски не удалены. Даже после редактирования исходного плана ранее сохранённый расчёт остаётся воспроизводимым.
- Модель: линейное движение между сохранёнными точками без географии дорог или препятствий; пересечения определяются по близости в один момент времени при заданном радиусе. Разброс скорости псевдослучаен и полностью определяется seed. Эти значения не являются игровыми прогнозами или телеметрией.
- **Общий Backup v20 не включает** сохранённые симуляции и подложки. Для временного переноса существует JSON-экспорт, без автоматического обратного импорта; полная поддержка ожидается в Backup v21.

## Проверки

`npm run verify` — тесты, сборка, проверка модулей и четырёх платформенных ZIP. `npm run test:browser:simulation` — сквозной сценарий в Chromium с Canvas, тестовым адаптером IndexedDB, созданием альтернативных запусков, просмотром таймлайна, сравнением, обнаружением повреждений и изоляцией профилей.

Не заявляется проверка установленных расширений в реальной игре или автоматическое получение игровых данных.
