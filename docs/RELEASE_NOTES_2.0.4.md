# MajesticToolkit 2.0.4 — Judicial System

## Реализованные операции

**Суды** (`#justice` → Суды → Суды и иерархия): сначала создайте ведомство через «+ Ведомство для суда» или используйте существующее. «+ Суд» создаёт судебный профиль, привязанный к конкретному ведомству. Выберите уровень инстанции, вышестоящий суд, место заседаний, описание и статус. Профили редактируются и архивируются. Реестр выводит иерархию, действующие назначения из Government Agencies, ведомственные решения и число правил подсудности. Старые судебные ведомства без профиля доступны в отдельном списке с действием «Настроить суд».

**Правила подсудности**: создайте правило, указав суд, стадию (первоначальное рассмотрение, апелляция, кассация, пересмотр), категорию дела и территорию. В обоих полях разрешено использовать `*` (все). Укажите правовое основание в соответствии с локальными RP-нормами и приоритет 0–100. Можно изменять, архивировать, восстанавливать и удалять каждое правило. Дубликаты одного сочетания суд/стадия/категория/территория запрещены.

**Проверить подсудность**: выберите стадию, категорию дела и территорию. Вы получите список судов с названиями и основаниями совпадений. Точные совпадения сортируются выше общих, затем по приоритету. Для апелляционной, кассационной или иной стадии можно указать исходный суд: поиск ограничится его цепочкой вышестоящих инстанций. Если подходящих правил нет, интерфейс сообщит об этом. Если вариантов несколько, итоговый выбор остаётся за пользователем.

## Целостность и совместимость

- Новые записи `court` и `jurisdiction` сохраняются в **том же `majesticGovernmentV6:` Government Store**, что и ведомства, должности и ведомственные решения. Второй копии данных нет.
- Используется действующая сериализованная очередь операций, проверка уникальности идентификаторов, профиля, внешних ключей, иерархии и активных зависимостей при каждом изменении.
- Нельзя удалить суд с правилами подсудности или с подчинёнными судами; нельзя архивировать суд, пока активны связанные правила или подчинённые суды.
- Сохранён Backup v18 и восстановление из прошлых версий. При импортировании проверяется отсутствие циклов, чужих профилей и недостающих связей.
- Новые данные включены в поиск Government & Justice по текущему профилю, поиск и историю открытых записей. Старые `#law`, `#government`, `#documents` без изменений.

## Ограничения

Система хранит настраиваемые **локальные RP-правила**, не проверяет их официальную юридическую силу. Она не присваивает права сотрудникам игровых серверов и не синхронизирует реестр между браузерами. Управление судебными делами, заседаниями и делопроизводством планируется на версии 2.0.5 и 2.0.6. Реальные учетные записи пользователей и автоматическое исполнение решений отсутствуют.

## Проверка

`npm test` — модульные тесты. `npm run test:browser:judicial` — Chromium E2E создания судов, правил и маршрутизации. `npm run test:browser:agencies` — регрессия ведомств. `MAJESTIC_E2E_BROWSERS=chromium python3 tests/browser-e2e.py` — E2E общих модулей. `npm run verify` — все четыре пакета расширения.
