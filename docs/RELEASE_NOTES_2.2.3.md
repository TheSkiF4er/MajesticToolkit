# MajesticToolkit 2.2.3 — Map Layers & Markers

## Доступная функциональность

В `#tactical` → **Карта** после загрузки собственной подложки теперь работает полный редактор аннотаций на Canvas:

- **Слои:** создание, изменение названий, скрытие/показ, блокировка редактирования, изменение порядка наложения и удаление пустого слоя. Нельзя удалить последний слой или слой с объектами.
- **Метки, линии и зоны:** кнопки инструментов «Метка», «Линия», «Зона», клики на карту для размещения вершин, явное завершение/отмена. Для каждой фигуры доступны название, описание, цвет и слой. Самопересекающиеся полигоны, вырожденные зоны и точки за пределами изображения отклоняются.
- **Выбор и редактирование:** кнопка «Выбор / перемещение» выбирает геометрию на Canvas; перетаскивание вершины изменяет её положение, перетаскивание линии или внутренней части полигона переносит фигуру целиком. Карточка выбранной фигуры меняет метаданные или слой; поиск и список объектов позволяют найти и центрировать нужный объект.
- **Отображение:** невидимые слои исключаются из отрисовки и hit testing; заблокированные остаются видимыми, но не редактируются. Выделенный объект показывает опорные вершины, длину в пикселях и площадь зоны. Если карта калибрована, дополнительно выводится протяжённость линии в игровых единицах.
- **Надёжность:** метки хранятся вместе с метаданными бинарной карты в IndexedDB; изменения атомарны и проверяют ревизию, поэтому параллельное редактирование разных вкладок вызывает явный конфликт вместо молчаливой потери данных. Отмена до 20 последних изменений действует в текущем сеансе. Профили изолированы. Замена подложки намеренно очищает старую разметку после подтверждения.
- **Перенос:** экспорт и подтверждаемый импорт разметки JSON, с обязательной проверкой версии, размеров и всех объектов. Изображение в JSON **не входит**. Файл карты и разметка **не входят в Backup v20**; перенос полного изображения запланирован на Backup v21.

## Проверка

- `npm run verify`: модульные тесты, сборки всех четырёх целевых платформ и проверка пакетов.
- `npm run test:browser:map`: регрессия существующего Canvas и калибровки.
- `npm run test:browser:map-layers`: Chromium E2E: создание слоёв и трёх типов объектов, изменение названий/цветов, физическое перетаскивание, блокировка, скрытие, отмена, JSON-импорт, восстановление после открытия вкладки и проверка изоляции профилей. Chromium работает с реальным Canvas, но IndexedDB в E2E подменён тестовым адаптером из-за ограничений браузерного раннера.

## Установка

Примените патч поверх полной версии 2.2.2 с сохранением структуры директорий. Выполните `npm run verify` и `npm run test:browser:map-layers`. Релизный ZIP изменений не включает `dist/` и `release/`.
