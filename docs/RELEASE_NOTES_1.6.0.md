# MajesticToolkit 1.6.0 — Forum Experience

- Workspace: адаптивная навигация по четырём группам, все 16 разделов, переключатель профиля, быстрый поиск и отдельные маршруты `?section=binder|navigation|customization|settings#forum`.
- Dashboard: избранные/недавние шаблоны, закладки, незавершённые жалобы и сроки, активные таймеры, документы, избранные серверы. Настройка порядка и видимости шести виджетов, обновление при изменении локальных данных. Таймеры и мониторинг используют существующие глобальные хранилища.
- Форум: единый Workspace с вкладками Биндер, Навигация, Тема, Оформление; контекст локальной жалобы, закладки и штатные действия, настройки темы и чтения. Сохранены горячие клавиши.
- Document Studio: явное подтверждение целевой вкладки перед вставкой текста документа; проверка разрешения, поддерживаемого домена и активного профиля; отправка только вручную.
- Popup и боковая панель: быстрые переходы в действующие инструменты. Существующие модули и Backup v14 сохранены, внешних зависимостей и новых разрешений нет.

## Обновление

Распакуйте ZIP с изменениями поверх исходников 1.5.9. Запустите `npm run verify` на Node.js 22, обновите расширение из соответствующей папки `dist/` и перезагрузите форумные вкладки. Для тестов браузера используйте `npm run test:browser` (Playwright или доступный Chromium). Оригинальное оформление форума остаётся значением по умолчанию.

## Ограничения

Браузерные сценарии используют автономные XenForo-фикстуры и имитацию API расширения; реальные авторизованные форумы и установка на устройствах требуют ручной проверки. Новый интерфейс использует существующие ES-модули; отдельные специализированные редакторы сохранены. Вставка документа — обычный текст, не PDF/HTML-разметка. Облачный AI не входит в выпуск. Публикация и подпись пакетов выполняются отдельно.
