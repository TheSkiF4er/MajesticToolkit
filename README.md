# MajesticToolkit

**MajesticToolkit** — самостоятельное расширение браузера для RP-форумов. Не требует собственной веб-платформы или сервера.

## Возможности

- Forum Toolkit: шаблоны BBCode, категории, переменные, сочетания клавиш и вставка в редакторы форума; штатные действия модерации без обхода разрешений.
- Complaint Manager: локальные жалобы, сроки и уведомления по открытым вкладкам; Evidence Studio: ссылки и таймкоды YouTube/Rutube/Twitch.
- Economy & Analytics: калькуляторы, сделки, финансовые операции, результаты игроков и семей, графики и CSV.
- Law Codex: импортируемые законы для каждого RP-сервера, редакции, поиск, сравнение, избранное и памятки.
- Government Tools: профили ведомств, решения, санкции, процессуальные шаблоны и фиксация применённых редакций законов.
- Document Studio: редактор и формы, локальные версии, экспорт многостраничного PDF. PDF формируется из изображений страниц, текст в нём не выделяется.
- External Integrations: OAuth PKCE для Google Docs, Google Sheets и Drive при наличии собственного Google OAuth Client ID; закладки на Fletcher Wiki и Docossum без скрытого извлечения данных.
- Productivity & UX: поиск по локальным разделам, ответы на основе локальных данных, темы, горячие клавиши, резервные копии.

**Важно:** в составе выпуска нет предзагруженной полной базы законов/предметов и нет онлайн-статистики всех игроков. Данные Law Codex добавляются пользователем. Нет собственного облачного ИИ и автоматического чтения Docossum/Fletcher Wiki.

## Требования и проверка

Node.js **22 LTS** для сборки; установка npm-зависимостей не нужна.

```sh
npm run verify
```

Команда запускает тесты, воспроизводимую сборку, проверку Manifest V3/разрешений/синтаксиса, создаёт ZIP-пакеты и проверяет SHA-256, каждый файл в ZIP и соответствие содержимому `dist/`.

## Установка для разработки

- **Chrome, Edge, Brave и аналогичные Chromium:** распакуйте `release/MajesticToolkit-1.0.0-chromium.zip` и откройте `chrome://extensions` → режим разработчика → «Загрузить распакованное расширение».
- **Firefox Desktop:** используйте `about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» → выберите `manifest.json` из распакованного `release/MajesticToolkit-1.0.0-firefox.zip`. Для постоянной установки необходимо подписать пакет через Mozilla AMO.
- **Firefox Android:** используется отдельный архив с адаптированным интерфейсом и без десктопной панели; доступность установки неподписанных дополнений зависит от версии и режима Firefox Android.
- **Safari:** `release/MajesticToolkit-1.0.0-safari.zip` содержит только ресурсы расширения; нужен контейнер Safari Web Extension, средства Apple и подпись. Это **не IPA/APP**, готового установочного приложения Safari в релизе нет.

После обновления сохраняйте **тот же идентификатор расширения** и профиль браузера. Не удаляйте установленную версию без экспортированной резервной копии.

## Данные и восстановление

При импорте резервной копии создаётся точка отката с SHA-256 в `storage.local` (макс. 20 МиБ). Она сохраняется при перезапуске браузера и позволяет вернуть прежние данные, включая записи форума/экономики/законов/документов. Импорт поддерживает предыдущие форматы v1–v9, основной ключ состояния не переименовывался. Восстановление доступно на вкладке «Резервные копии» и при ошибке загрузки состояния. Снимок не включает OAuth-токены и не изменяет посторонние ключи хранения. Для копий свыше 20 МиБ **сначала экспортируйте JSON в файл**. Снимок не заменяет внешние бэкапы.

## Подача в Mozilla AMO

Сборка Firefox содержит декларацию данных: обязательная передача отсутствует, необязательные категории используются при пользовательском подключении Google. Официальный сайт дополнений требует указать категории передачи данных при загрузке. См. [инструкцию AMO](docs/AMO_SUBMISSION.md) и [политику приватности](docs/PRIVACY.md). Стабильный Gecko ID: `majestictoolkit@theskif4er.github.io`; не менять после первой публикации.

## Безопасность и интеграции

Разрешения на RP-форумы и видеосайты запрашиваются отдельно. Контентные скрипты читают данные через ограниченный интерфейс фонового процесса; в Chromium доступ к `storage.local` из недоверенных контекстов дополнительно отключён. Публикация сообщений/наказаний не должна происходить без действий пользователя. Подключение Google требует собственного OAuth-клиента, зарегистрированных Redirect URI и ограниченного доступа к файлам. Автоматическая синхронизация с Docossum не выполняется без согласования с владельцем.
