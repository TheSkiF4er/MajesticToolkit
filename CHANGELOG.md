# История изменений

## 1.2.0 — Server Monitor & Player Profiles (2026-10-22)

- Новый раздел с реальным каталогом серверов Majestic RP и Russia Online, получаемым из публичного `meta/general` после согласия пользователя и отдельного необязательного разрешения на API.
- Запрос реального онлайна с валидацией числовых полей и фиксированного источника. При недоступности данных — явно указанный неизвестный статус, без поддельных значений.
- Избранные серверы, фильтр проектов, локальный кеш и время последнего подтверждённого снимка. Необязательное автообновление раз в 5 минут при открытой видимой вкладке.
- Кнопка сохранения карточки общедоступного профиля в XenForo без обращения к приватным API. Привязка к игровому профилю, редактирование/пересохранение и удаление.
- Резервные копии v11, перенос ранее сохранённых карточек, откат и удаление карточек вместе с локальным игровым профилем. Совместимость v1–v10.
- Регрессионные тесты API-контрактов, прав доступа, XSS-экранирования, хранения, восстановления и совместимости четырёх MV3-сборок.


## 1.1.0 — XenForo Integration & Competitor Parity (2026-10-22)

- Общее ядро XenForo для Majestic RP и Russia Online: валидация доменов, определения страницы темы и публичного профиля.
- Исправлена изоляция шаблонов и настроек между двумя форумами: выбор активного профиля по `forumUrl`, а не только по текущему глобальному ID.
- Реальная пользовательская навигация в шапке XenForo: создание, редактирование, удаление и отображение ссылок HTTPS с привязкой к профилю или всем профилям.
- Просмотр доступных на текущей странице `/members/` публичных показателей без запросов к скрытым API и без сохранения персональных данных.
- Более устойчивый биндер для Froala и `textarea`: восстановление позиции курсора, безопасная вставка BBCode, защита горячих клавиш других полей.
- Открытие штатных действий закрытия/открытия и перемещения темы через разрешённые элементы DOM, с подтверждением пользователем и без автоматической отправки форм.
- Хранение новых ссылок и транзакционная замена с откатом; формат резервной копии v10, совместимость с v1–v9, точки восстановления SHA-256.
- Новые регрессионные тесты XenForo, хранилища, резервных копий и пользовательского интерфейса; четыре воспроизводимые сборки Manifest V3.

**Ограничение:** полные E2E на авторизованных страницах конкретных тем, расширений XenForo и мобильных браузерах не проводились. Функциональность зависит от реально доступных DOM-элементов и полномочий пользователя.

## 1.0.0 — Stable release candidate (2026-10-21)

- Исправлен динамический `import()` фонового Chromium MV3: статические модули и Manifest `background.type=module`.
- Контентные скрипты форума и видеосервисов больше не получают дамп `storage.local`; получают минимально необходимую информацию через проверенные фоновые сообщения.
- Ограничен доступ недоверенных контекстов к локальному хранилищу, где поддерживается API `setAccessLevel`.
- Добавлена проверяемая SHA-256 точка отката, сохранение до импорта, восстановление после прерывания и UI экстренного восстановления.
- Подготовлены четыре отдельные сборки: Chromium, Firefox Desktop, Firefox Android и Safari WebExtension resources.
- Исправлено открытие боковой панели Chromium через ID текущего окна.
- Улучшена мобильная компоновка, доступность сенсорных кнопок, реакция на системное снижение анимаций.
- Добавлены регрессионные тесты восстановления и release gates: статическая проверка всех модулей, разрешений, контрольные суммы и сравнение содержимого ZIP с собранными файлами.
- Документированы ограничения выпуска, миграции и процесс публикации.

**Особенность источника:** предоставленный архив с названием версии 0.10.0 внутри содержит Manifest/package версии 0.9.0 и 173 теста. В 1.0.0 повторно внесены обязательные исправления безопасности и сборки, которые отсутствовали в этих исходниках.

**Статус:** исходники и дистрибутивы проверены автоматизированно. Не пройдены испытания в установленных браузерах на реальных сайтах; магазины расширений ещё не содержат этот релиз.

## 1.3.0 — External Knowledge & Workspace (2026-10-22)
- Новый полноценный раздел «Центр знаний»: локальная библиотека документов, документных и процессуальных шаблонов, законов, памяток и шаблонов ответов XenForo.
- Двусторонние аннотированные связи между локальными записями, сохранёнными ссылками Fletcher Wiki / Docossum и файлами Google Docs/Sheets. Поиск, фильтр, переход к исходнику, удаление и обнаружение отсутствующих источников.
- Прямые ссылки Fletcher Wiki для Majestic RP и Russia Online, удобное сохранение пользовательских HTTPS-закладок. Без обхода защит или автоматического сбора данных с внешних сайтов.
- Реальная операция Google Drive Files.copy для выбранного пользователем шаблона (OAuth и scope drive.file; чужие недоступные файлы могут вернуть 403).
- Отдельное профильное хранилище и проверка связей; резервная копия схемы v12, импорт v1–v11, восстановление после ошибки и удаление данных профиля.
- Регрессионные тесты: маршруты, XSS-экранирование, изоляция профилей, сохранение, импорт, двусторонние связи, Google API и отказ доступа.
